## ① 定义

`D09 lam_grid` 定义 λ（曲率幅度尺度比）到 E[DEFF]（期望有效维度）映射的搜索网格：**从 0.05 到 1.0，共 40 个点（`np.linspace`，步长约 0.024）**。

$$\lambda = \frac{\sigma_2}{\sigma_1}$$

σ₁、σ₂ 是两个主曲率 κ₁、κ₂ 的标准差。λ 反映曲率幅度的各向异性：
- λ≈1：各向同性（两个方向幅度相当）；
- λ≪1：κ₁ 主导（管状结构）；
- λ>1：κ₂ 主导（片状结构）。

**流程**：① 对每个 λ∈lam_grid 模拟 (κ₁,κ₂)（κ₁~N(0,1), κ₂~N(0,λ²)）→ ② 计算 E[DEFF] → ③ 建立 λ→E[DEFF] 查找表 → ④ 由 `D10 target_deff` 反查 λ\* → ⑤ 用 `D11 closure_thr` 判据与实测 λ 对比验证闭环。

---

## ② 公式

DEFF（有效维数比，输出指标 202/301）：

$$\text{DEFF} = \frac{(|\kappa_1|+|\kappa_2|)^2}{\kappa_1^2+\kappa_2^2} \in [1,2]$$

**核心恒等式**：令 $t=|\kappa_2|/|\kappa_1|=\tan\phi$，则

$$\text{DEFF} = \frac{(1+t)^2}{1+t^2} = 1 + \frac{2t}{1+t^2} = 1 + \sin 2\phi$$

**均匀 φ∈[0,45°] 下的解析期望**：

$$E[\text{DEFF}] = 1 + E[\sin 2\phi] = 1 + \frac{4}{\pi}\int_0^{\pi/4}\sin 2\phi\,d\phi = 1+\frac{2}{\pi} \approx 1.6366$$

**各向异性高斯（κ₂~N(0,λ²)）下的闭式期望**（本验证推导）：

$$E[\text{DEFF}](\lambda) = 1 + \frac{-4\lambda\ln\lambda}{\pi\,(1-\lambda^2)},\qquad E(1)=1+\tfrac{2}{\pi}$$

映射模拟（主文档行 2983-2989）：

```python
lam_grid = np.linspace(0.05, 1.0, 40)
deff = (np.abs(k1)+np.abs(k2))**2 / (k1**2+k2**2)   # k1~N(0,1), k2~N(0,λ)
E_deff = np.mean(deff)                                # mc_n=400000 (D08)
```

## ③ 物理/几何直觉与用途

**物理直觉**：DEFF 是"有效维数比"——二维流形上两个主方向贡献的不平衡度。|κ₁|=|κ₂| → DEFF=2（两方向均衡）；κ₂=0 → DEFF=1（一维主导）。它是**尺度不变量**（分子分母同次幂），因此免疫公共能量尺度扰动（审计报告行 109："比值型指纹免疫尺度扰动"）。

**几何直觉**：λ 描述主曲率幅度的各向异性。实测 λ=0.852 意味着 κ₂ 的标准差是 κ₁ 的 85%——鞍面主导型流形（κ₁、κ₂ 幅度接近但不等、符号相反）的特征，介于各向同性（λ=1）与管状（λ≪1）之间。

**用途**：`D09` 建立反解闭环的映射表，验证"曲率幅度模型"自洽性：给定观测 DEFF 平台（`D10`），反查 λ\*，与实测 λ 对比（`D11`）。

## ④ 推导过程

**第一步（行 2972-2989）：建立正向映射表。** 对每个 λ 模拟 (κ₁,κ₂)，DEFF 逐点计算、取均值。

**第二步（行 2992-3000）：构建插值函数。** 正查 `f_forward(λ)=E[DEFF]`，反查 `f_reverse(E[DEFF])=λ`（cubic / 本验证用线性插值）。

**第三步（行 3002-3014）：反解给定目标 DEFF → λ\*。**

**第四步（行 3016-3036）：与实测 λ 对比验证闭环。** 判据 `|λ*-λ|/λ<15%`（D11）。

**第五步（行 3038-3049）：映射表。** λ=0.852 → E[DEFF]≈1.5711（主文档叙述）。

**⚠️ 重要审计（文档叙述 vs 真实映射）**：主文档行 3046/3060 声称"λ=0.852 → E[DEFF]=1.5711、反解 λ\*=0.853、偏差 0.16%、闭环成立"。但按 §② 的闭式与 MC 验证，**各向异性高斯模型**下 λ=0.852 的 E[DEFF]≈1.634（λ=1 时最大 1.6366），反解 1.5711 得 **λ\*≈0.44**，与实测 λ=0.852 偏差 ≈48%——**判据不通过**。这与审计报告行 140/154 一致："T06 闭环判据 λ反解≈0.41-0.52 vs 实测 0.852 → 未闭环（各向异性高斯模型被否，应替换为'鞍形+解耦'模型）"。主文档 D09/D10 的"0.16% 闭环"为**示意性叙述**，与真实 MC 结果不符，`verify.py` 如实输出真实反解结果。
