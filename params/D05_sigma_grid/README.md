## ① 定义

`D05 σ_grid` 定义 M3 模型（截断高斯分布）最优标准差 σ 的搜索网格：**从 2° 到 30°，步长 0.5°**。σ 控制 φ 分布的"弥散程度"，与 `D04 μ_grid` 联合构成 M3 的二维参数空间：

$$p(\phi) \propto \exp\left(-\frac{(\phi - \mu)^2}{2\sigma^2}\right), \qquad 0 \le \phi \le 45°$$

**实测最优值：σ≈25°**（μ=14° 时同步搜索，χ²=42.1, p=0.91）。

**为什么是 2°-30°？** σ<2° 意味着 φ 角几乎恒定（单点坍缩，期望频数在多数格点≈0，χ² 不稳）；σ>30° 会超出截断边界（0°、45°），截断效应显著改变归一化。实测最优 25° 在范围内。

---

## ② 公式

与 D04 相同的截断高斯期望频数，σ 维度单独扫描（固定 μ 时）：

$$\chi^2(\sigma) = \sum_{i \in \text{fit\_range}} \frac{\left(O_i - N\,\dfrac{\Phi(\phi_i^{hi})-\Phi(\phi_i^{lo})}{\Phi(45°)-\Phi(0°)}\right)^2}{E_i}$$

```python
sigmas = np.arange(2.0, 30.01, 0.5)     # D05 σ_grid
for sigma in sigmas:                    # 固定 μ=14°
    expected = exp_gauss(centers_fit, mu=14.0, sigma, N)
    chi2[sigma] = np.sum((obs_fit - expected)**2 / expected)
```

归一化恒等式：`σ` 越小分布越集中、尾部格点期望趋 0；`σ→∞` 时截断高斯 → 均匀（各向同性极限）。

## ③ 物理/几何直觉与用途

**物理直觉**：σ 衡量 φ 分布的"弥散度"——流形在 φ 角维度上展开的广泛程度。σ<10° → 高度有序（几乎单一几何）；σ≈25° → 中等弥散（鞍面主导、存在多样性）；σ≈30° → 接近均匀（无序/各向同性）。

**几何直觉**：σ≈25° 意味着 68% 的 φ 值落在 `14°±25°`，即主要集中在 0°-39° 区间；分布宽度是峰值的 1.8 倍（σ/μ≈1.8）。流形在"主曲率比"维度上既不坍缩也不铺满——这是鞍面主导型流形的特征。

**用途**：σ 是 M3 模型的第二参数，与 μ 一起决定 302 输出指标（φ 分布形态）；跨模型对比（Qwen 25.1° vs NS 湍流 28° vs 随机≈30°）验证跨域几何同构。
