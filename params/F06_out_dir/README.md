## ① 定义

`F06 out_dir` 定义结果输出的目录路径，具备**自动回退**机制：运行时按优先级尝试候选路径，返回第一个"可创建且可写"的目录，保证脚本不因路径问题中断。实测落点为 `E:NS数据/桌面`（审计口径；源码首选 `E:\NS数据全部\reverse_256_render\ai_whitebox_with_curvature.csv`，目录不存在则回退到脚本所在目录）。

```python
CANDIDATE_DIRS = [
    "/data/outputs",    # 首选: 共享存储
    "/tmp/results",     # 备选: 临时目录
    "./outputs",        # 备选: 当前目录
]
```

## ② 公式

```python
out_dir = first(p for p in CANDIDATE_DIRS if writable(p))
# 全部失败 → 兜底 "."  (当前工作目录)
```

其中可写性检查为"写-删测试"（主文档第 4777-4788 行）：

$$\text{writable}(p) \iff \exists\, f=\text{open}(p/.write\_test,\,'w')\ \text{写成功}\ \wedge\ \text{remove}(f)\ \text{成功}$$

## ③ 物理/几何直觉与用途

**物理直觉**：指纹实验是"测量-存档-复现"的闭环——每一份 Gamma 剖面、DEFF 曲线、溯源判据都需要落地才能跨实验对比。输出落点是闭环的"存储端"。不同环境（超算共享存储 / 本地磁盘 / 容器 tmpfs / Windows 数据盘）目录结构迥异，权限与挂载状态不可预期；自动回退本质是**让系统在最坏情况下优雅降级而不是崩溃**——和 F01 的 OOM 降档、G05 的 API 超时护栏是同一鲁棒性设计哲学在不同资源轴（磁盘 vs 内存 vs 时间）上的体现。

**用途**：① 统一管理输出产物（JSON/CSV 数据、PNG/HTML 图表、日志、npy 中间数据）；② 跨环境可移植（同一脚本在超算与笔记本上都能跑）；③ 避免批处理任务因一个坏路径整体中断；④ 按子目录组织实验类型（fingerprints/charts/logs/checkpoints），便于归档与复现。

## ④ 推导过程

**推导 1：为什么用"写-删测试"而非"存在性检查"**。目录存在 ≠ 可写（如只读挂载、权限不足、磁盘满）。只有真实写入一个探针文件再删除，才能验证"创建-写入-删除"全链路权限。代价是一个微小 I/O，换来对权限/挂载状态变化的实时感知。

**推导 2：回退单调性与确定性**。候选列表按优先级固定排序，`first-available` 规则保证：同一环境下多次调用返回同一目录（确定性）；若首选恢复可用，自动回到首选（单调回归）。这保证了实验产物的可预测位置。

**推导 3：兜底语义**。全部候选失败时返回 `"."`（当前工作目录）：即使无处可写，也把产物落在进程所在位置而非丢弃，最大限度保留数据；同时打印警告。这是"永不静默失败"原则——宁可降级不可丢数据。
