# D11 closure_thr — 闭环判据阈值

> 组：D 统计/裁决 | 状态：✅ 已用（T06 未闭环） | 数据源：主文档行 3208-3327、《参数完整定义与公式.txt》行 236-243、《参数审计与实验报告.txt》行 62、140、154

---

## ① 定义

`D11 closure_thr` 定义反解闭环的判据阈值，**固定为 15%**。反解闭环：`D09` 建立 λ→E[DEFF] 映射 → `D10` 反查 λ\* → `D11` 比较 λ\* 与实测 λ：

$$\text{偏差} = \frac{|\lambda^* - \lambda_{\text{实测}}|}{\lambda_{\text{实测}}}$$

- 偏差 < 15% → 闭环成立（模型自洽）；
- 偏差 > 15% → 闭环不成立（模型存在结构缺陷）。

**实测状态：已用。T06（闭环判据）标记为"未闭环"。**

---

## ② 公式

```python
thr = 0.15                                # D11 固定值
deviation = abs(lambda_star - lambda_meas) / lambda_meas
closed = deviation < thr                  # 判据
```

偏差分级：

| 偏差范围 | 判定 | 含义 |
|----------|------|------|
| <5% | 强闭环 | 反解与实测几乎一致，模型高度自洽 |
| 5-15% | 弱闭环 | 反解与实测接近，模型基本自洽 |
| >15% | 未闭环 | 反解与实测偏离，模型有结构缺陷 |

---

## ③ 物理/几何直觉与用途

**物理直觉**：闭环判据检验"正向建模-反向推理"的一致性。若模型正确，由 DEFF 平台反解的 λ\* 应与直接测量的 λ 吻合到数值噪声以内。阈值太紧（5%）会被 MC 噪声、数值近似误伤；太松（20%）则无法区分"接近"与"偏离"。

**几何直觉**：15% 对应约 2.5σ 的置信区间（主文档行 3235）。λ 的变化 15% 大致对应 DEFF 变化 ΔE≈2-3%（因 dE/dλ 平缓），因此该阈值对映射噪声（<0.1%）有充足余量，只对真正的模型缺陷敏感。

**用途**：`D11` 是反解闭环的**最终裁决门槛**。实测中按主文档叙述 NS 偏差 0.16%（强闭环）、AI 偏差 6.86%（弱闭环）——**但 T06 审计标记为"未闭环"**，原因见 ④/⑤。

---

## ④ 推导过程

**第一步（行 3241-3248）：获取反解 λ\*。** 来自 D09 映射 + D10 目标。

**第二步（行 3250-3265）：计算偏差。** 主文档叙述：NS 0.16%、AI 6.86%。

**第三步（行 3267-3288）：应用判据。** 主文档叙述：两者均 <15% → 闭环成立。

**第四步（行 3290-3300）：阈值敏感性表。** 5% 阈值下 AI（6.86%）未通过；15%/20% 下均通过。

**第五步（行 3302-3322）：产出。** 注：T06 记录为"未闭环"，可能与跨域口径有关——"跨域闭环"需同时满足 AI 的 DEFF 值与 NS 平台一致，而 1.5920 vs 1.5711 差 1.3% 导致闭环被否定。

**⚠️ 重要审计（判据逻辑 vs 真实结果）**：判据本身（15%）定义清晰；但**真实 MC 反解**（见 D09/D10）在各向异性高斯模型下得到 λ\*≈0.44（NS）/0.52（AI），与实测 λ=0.852 偏差 ≈48%/39%，**远超 15%** → 未闭环。审计报告行 140："λ反解≈0.41-0.52 vs 实测 0.852 → 未闭环（各向异性高斯模型被否）"；行 154 建议将该底层模型替换为"鞍形+解耦"模型。主文档 D11 的"0.16%/6.86% 闭环成立"为示意叙述。`verify.py` 同时验证判据逻辑正确性与真实未闭环结果。
