## ① 定义

`C02 ks` 定义主成分扫描的 k 值列表，固定为 **`[1, 2, 4, 8, 16]`**（2 的幂次，对数间隔）。

用于扫描不同 k 值下的能量保留率，绘制"主成分数 → 能量占比"的**压缩比曲线**（主文档行 1836-1846）。

```python
C02 ks = [1, 2, 4, 8, 16]
```

- `k=1`：测最集中方向的单方向信息量；
- `k=16`：测是否已覆盖绝大部分能量——若前 16 个主成分覆盖 >90% 能量 → 模型高度集中；若需 >50 个主成分 → 模型弥散。

**默认/实测范围**：`[1,2,4,8,16]`（状态：理论）。

---

## ② 公式

对每个 `k ∈ ks`，计算前 k 个主成分累积能量占比（主文档行 1842-1844）：

$$\text{energy\_ratio}(k) = \frac{\sum_{i=1}^{k}\lambda_i}{\sum_{i=1}^{d}\lambda_i},\qquad k \in \{1,2,4,8,16\}$$

对应代码：

```python
ks = [1, 2, 4, 8, 16]
eigvals = np.linalg.eigvalsh(cov)[::-1]      # 降序
total = np.sum(eigvals)
for k in ks:
    ratio = np.sum(eigvals[:k]) / total      # 能量保留率
```

曲线性质：`energy_ratio(k)` 关于 k **单调不减**、取值于 `[0,1]`、`energy_ratio(16) ≥ energy_ratio(1)`。

## ③ 物理/几何直觉与用途

**物理直觉**：压缩比曲线回答"信息在多少方向上铺开"。谱集中时曲线**陡升**（前少数 k 已带走大部分能量）；谱弥散时曲线**缓升**。k_proj 与 up_proj 的曲线对比（主文档行 1890-1896）显示：k_proj 在所有 k 上能量占比更高 → 更集中、更可压。

**几何直觉**：`energy_ratio(4) ≈ 0.62-0.70` 正好对应 B01 C-子空间（M=3）的能量占比——说明"前 4 个主成分 ≈ 前 3 个奇异主方向 + 1 个余量"是同一几何结构的两种度量口径（主文档行 1870-1871）。

**用途**（主文档行 1848-1931）：
1. **压缩比曲线**——与 C01 互补，画出完整"能量↔k"曲线；
2. **跨投影排序**——k_proj 各 k 能量占比均高于 up_proj，量化投影可压性排序；
3. **跨模型稳定性**——Qwen 与 GPT-2 的 k_proj 曲线几乎重合（0.93 vs 0.92 @k=16），证明集中度是跨模型稳定几何规律；
4. **压缩策略建议**——保留前 16 个主成分（≈93% 信息），可减少 98% 存储（主文档行 1930）。

## ④ 推导过程

**第 1 步：谱分解。** 同 C01，得降序特征值谱 `{λᵢ}` 与总量 `T = Σλᵢ`。

**第 2 步：逐点能量。** 对 `k ∈ {1,2,4,8,16}` 计算 `E_k = (Σ_{i≤k}λᵢ)/T`。

**第 3 步：曲线解读。** 用 `E_k` 序列刻画集中度：
- 单方向信息量 `E₁`：k_proj 0.38 vs up_proj 0.22 → k_proj 第一主方向更"重"；
- C-子空间占比 `E₄`：0.70 对应 B01 M=3 的 Gamma≈0.62-0.68；
- 近覆盖判据 `E₁₆`：>0.90 → 高度集中（Qwen k_proj 0.93 ✓）；≈0.8 → 中等（up_proj 0.82）。

**第 4 步：与 C01 一致性。** `E₆=0.5、E₁₃≥0.9`（C01 扫描表）与 `E₁₆=0.93` 同源：同一谱下，C01 从能量反解 k90=13，C02 从 k 正算能量 0.93，二者相互校验（主文档行 1927）。

**第 5 步：工程导出。** 前 16 个主成分覆盖 93% 信息，对应谱压缩理论存储比例 `16/896 ≈ 1.8%`，即减少 ≈98% 存储。
