## ① 定义

`T05 尖峰显著性` 是判断 φ 分布（主曲率角 `φ = arctan(|κ₂|/|κ₁|)` 的分布）中是否存在**统计显著的异常尖峰**的卡方判据。通过比较「均匀/平滑背景模型」与「背景 + 尖峰分量模型」的拟合优度，裁决尖峰分量是否显著：

- `Δχ² > 5.99`：尖峰模型显著优于平滑模型 → **尖峰存在** 🚨
- `Δχ² ≤ 5.99`：尖峰模型不显著优于平滑模型 → **尖峰不显著** ✅

实测状态：**M4 否决 ✓**（φ 分布为平滑单峰截断高斯，无异常角度聚集）

## ② 公式

$$\Delta\chi^2 = \chi^2_{M3} - \chi^2_{M4} > 5.99$$

临界值来源（自由度差 `df = 2`，显著性水平 `α = 0.05`）：

$$\chi^2_{0.05}(2) = 5.99$$

其中 M3 = 截断高斯（2 参数 μ, σ），M4 = 高斯背景 + 尖峰分量（在 M3 基础上增加 `a` 强度、`sp` 峰宽 2 个参数）。

| Δχ² | 判定 | 物理含义 |
|------|------|---------|
| > 5.99 | 尖峰显著 | φ 分布有异常集中角度 → 流形特定方向过度聚集 |
| ≤ 5.99 | 尖峰不显著 | φ 分布平滑，无异常角度聚集 |

## ③ 物理/几何直觉与用途

- **φ 角的几何意义**：`φ = arctan(small/big)` 是逐点主曲率比值角度，各向同性时 φ 应均匀/平滑分布（中位 22.5°）。若 φ 分布出现异常尖峰，说明流形在某个特定角度过度聚集——对应「每点锁 π/2」式的伪结构或退化。
- **M4 被否决的物理含义**：φ 分布是平滑的单峰分布（截断高斯），流形各向异性平滑分布，没有异常角度聚集。这为「共模幅度 × 独立比值」解耦机制（φ 形状由纯比值几何决定）提供了统计依据。
- **用途**：统计裁决层的守护闸门，防止把拟合伪影误判为物理结构；也是判断「鞍形主导」结构是否附带方向性偏好的依据。

**诚实口径标注**：主文档公式块写 `Δχ² = χ²_M1 − χ²_M4`（M1 为 0 参均匀零模型，得 245.3−39.8=205.5>5.99）。但该式是对零模型的绝对改善，仅能说明「背景远非均匀」；**是否引入尖峰分量**的正确裁决是相邻模型增量检验 `Δχ² = χ²_M3 − χ²_M4 = 2.3 < 5.99`（df=2）。文档正文与审计结论均采用后者（M4 否决、无尖峰）。

## ④ 推导过程

**Step 1 — 四模型卡方拟合（实测，`_phi_fit_chi2.py` 口径）。**

| 模型 | χ² | 参数数 | 说明 |
|------|----:|:------:|------|
| M1 均匀 | 245.3 | 0 | U[0,45°] 零模型 |
| M2 截断均匀 | 98.7 | 1 | U[0,θ*] |
| M3 截断高斯 | 42.1 | 2 | N(μ,σ)|[0,45°] |
| M4 高斯+尖峰 | 39.8 | 4 | 背景 + 尖峰(a, sp) |

**Step 2 — 相邻模型增量检验（是否引入尖峰）。**

$$\Delta\chi^2_{M3 \to M4} = 42.1 - 39.8 = 2.3 < 5.99$$

M4 增加 2 个参数（a 和 sp），χ² 仅降低 2.3，低于 `χ²_{0.05}(2)=5.99` 的临界值 → **增加尖峰分量没有显著改善拟合** → M4 否决。

**Step 3 — 最优尖峰参数趋于零。** 搜索得到最优 `a ≈ 0.010`（≈0）、`sp ≈ 2.4°`：尖峰强度可忽略，即使加入尖峰其强度也趋近 0。

**Step 4 — 似然比判据的统计学依据。** 嵌套模型（M4 ⊃ M3）的似然比统计量渐近服从 χ² 分布，自由度差 = 新增参数数 = 2。在 α=0.05 下单侧临界值 `χ²_{0.05}(2)=5.99`，即「Δχ²>5.99 才有 95% 置信认为尖峰真实存在」。

## ⑤ 数值验证

| 项目 | 值 | 判定 |
|------|----|----|
| χ²_M3（截断高斯） | 42.1 | — |
| χ²_M4（高斯+尖峰） | 39.8 | — |
| Δχ²(M3→M4) | 2.3 | < 5.99 → M4 否决 ✓ |
| 临界值 χ²_{0.05}(2) | 5.99 | — |
| 最优 a / sp | ≈ 0.010 / ≈ 2.4° | 尖峰强度可忽略 |
