# A03 gen_len / ngen — 生成 token 数

> 组：A 模型与任务 | 状态：✅ 已用 | 数据源：主文档行 67-169、《参数完整定义与公式.txt》行 25-32、《参数审计与实验报告.txt》行 36

---

## ① 定义

`A03 gen_len/ngen` 控制模型生成的 **token 总数**（正整数）。它直接影响曲率统计的稳定性——生成的 token 按 `B04 TOK_PER_FRAME=8` 分帧，**帧数 = gen_len / TOK_PER_FRAME**（主文档行 69）：

```
64 token  → 8 帧
96 token  → 12 帧
256 token → 32 帧
```

默认实测值：`64 / 96 / 60`（规格行 30；范围 64-96 token）。

---

## ② 公式

核心关系（主文档行 69）：

$$
N_{\text{frames}} = \frac{\text{gen\_len}}{\text{TOK\_PER\_FRAME}} = \frac{\text{gen\_len}}{8}
$$

对每帧独立计算曲率三件套（版本 A），帧级统计量随帧数收敛：

$$
K\%_f, \; \text{DEFF}_f, \; H^{(med)}_f \quad (f=1,\dots,N_{\text{frames}})
$$

收敛判定（主文档行 136）：
- `K%` 稳定在 NS 饱和态 **57.42%** 附近且不再随长度显著上升；
- `DEFF` 帧间 CV < 3%（T02 稳态）；
- `Hmed` 持续下降、趋近 0（极小曲面极限）。

帧间波动系数：$\mathrm{CV} = \mathrm{std}_f(\mathrm{DEFF}_f)/\mathrm{mean}_f(\mathrm{DEFF}_f)$

---

## ③ 物理/几何直觉与用途

**物理直觉**：指纹测量 = 对激活流形的统计采样。gen_len 是"采样预算"——样本太少时统计量（K%、DEFF、Hmed）波动大、不稳定；样本足够时统计量**收敛到平台值**（主文档行 69）。这与统计物理中"系综越大涨落越小"完全对应。

**几何直觉**：K% 描述流形上鞍面点比例（鞍形主导→TPMS 结构接近度），DEFF 描述内禀维度（→2 极小曲面 / →1 圆柱）。短链只覆盖流形的局部区域，曲率统计停留在"上升期"；长链才覆盖到饱和区，锚定到 NS 耗散态（K%=57.42%）。

**用途**：
1. 决定曲率统计的稳定性与收敛性（主文档行 69）；
2. 扫描 3-5 档长度，找到"统计稳定"与"计算成本"的平衡点（主文档行 169）；
3. 收敛后的指纹才是"锁定态"指纹，可作溯源参考（主文档行 166）。

## ④ 推导过程

完整操作流程（主文档行 67-169）：

1. **固定基线参数**（行 71-82）：`A01=Qwen2.5-0.5B-Instruct`、`A02=宇宙膨胀句`、`B04=8`、`B07=15`、`B08=8`、`H01 seed=0`，让 gen_len 成为唯一变量。
2. **短链测试（96 token = 12 帧）**（行 84-100）：`N_NEW=96` 运行 `_ai_versionA_dynamic.py` → 末帧 K%=45.6%、DEFF 均值 1.583。观察：斜率 +0.59%/帧，**上升期**，未饱和。
3. **中等链测试（128 token = 16 帧）**（行 102-112）：K% 末帧约 50-52%、DEFF 约 1.58、Hmed 约 1.0-1.2。斜率降至 +0.4%/帧，**趋缓期**。
4. **长链测试（256 token = 32 帧）**（行 114-124）：K% 末帧 **57.33%**（锚定 NS 饱和态 57.42%，误差 <0.2%）、DEFF=1.584、Hmed=0.757。斜率 +0.26%/帧，**饱和区**。
5. **收敛性判断**（行 126-136）：三档对比表：

| 长度 | 帧数 | K%末帧 | DEFF均值 | Hmed末帧 | 斜率 | 状态 |
|------|------|--------|----------|----------|------|------|
| 96 | 12 | 45.6% | 1.583 | ~1.2 | +0.59%/帧 | 上升期 |
| 128 | 16 | ~52% | ~1.58 | ~1.1 | +0.4%/帧 | 趋缓期 |
| 256 | 32 | 57.33% | 1.584 | 0.757 | +0.26%/帧 | 饱和区 |

6. **参数配合**（行 138-149）：帧内波动过大（CV>3%）→ 增大 B05/B07/TOK_PER_FRAME；收敛慢 → 增大 N_NEW（512/1024）或减小 TOK_PER_FRAME。
7. **可复现报告**（行 151-167）：输出三档 K%/DEFF/帧数 → 结论"gen_len≥256 进入几何锁定态，K% 收敛 57.3%，DEFF 锁定 1.58±0.02"。

## ⑥ 与关联参数的关系

| 关联参数 | 关系 |
|----------|------|
| B04 TOK_PER_FRAME | 帧数 = gen_len/8，A03 的直接换算对象 |
| B05 SAMPLES_PER_FRAME | 每帧采样密度，帧内波动大时可从 18 增至 24 |
| B07 K_NN_CURV | 曲率近邻数，波动大时 15→20 平滑估计 |
| B08 NFRAME | 构建曲率指纹的帧数（=8），A03 须≥NFRAME 才有完整指纹 |
| A01/A02 | gen_len 扫描在固定模型与 prompt 下进行 |
| H01 seed | 固定随机状态，保证不同 gen_len 扫描可复现 |
| T02 非稳态告警 | DEFF 帧间 CV>3% 告警；A03 越长 CV 越小 |
| T01/T03 | DEFF 平台与 K% 槽位裁决依赖长链收敛值 |
