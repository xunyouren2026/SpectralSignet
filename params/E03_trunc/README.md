## ① 定义

`E03 trunc` 定义**截断扰动**的两个强度：**保留 50%** 与**保留 25%**。

截断是文本扰动家族的第二类：**同一内容、部分保留**。系统对输入 token 序列做截断处理（保留前半部分、丢弃后半部分），重新计算截断后文本的指纹，验证指纹在极端信息残缺下是否仍能溯源。

```python
trunc_ratios = [0.5, 0.25]   # 保留 50% 和 25%
# 例如：原始 100 token -> 截断到 50 token / 25 token
```

**n=6**：两个截断比例 × 3 个溯源实例 = 6 个测试样本——每个比例 3 个样本足以证明趋势，是对截断扰动的最小有效测试量。

## ② 公式

对原始输入（token 数 `T`）按比例截断：

$$k \;=\; \max\big(\lfloor T \cdot r \rfloor,\; 4\big),\qquad r \in \{0.5,\; 0.25\}$$

（源码 `_qwen_robustness.py`：`k = max(int(full_ids.shape[1]*frac), 4)`，保底 4 token 以保证可提取指纹。）

截断后指纹 `g_r` 与基线指纹的 MAD：

$$\text{MAD}(r) \;=\; \frac{1}{d}\sum_{k=1}^{d}\big|g_{r,k} - \text{baseline}_k\big|$$

分离度（两家族对同一截断响应的可分性）：

$$\text{separation} \;=\; \text{MAD}_{GPT2}(r) - \text{MAD}_{Qwen}(r)$$

## ③ 物理/几何直觉与用途

**物理直觉：截断是"信息残缺下的结构保持性"测试。** 指纹来自模型激活的几何结构（β 谱能量集中 + 曲率特征）。若指纹是真正的"模型身份"，那么即使只喂给模型一半、甚至四分之一的输入，其**固有结构签名**仍应保留——因为身份来自模型的权重/架构，而非输入内容。截断检验的正是：指纹在输入大幅残缺时，是**结构稳定**（身份信号）还是**内容驱动**（信号崩解）。

**测试目标：**
| 截断比例 | 保留内容 | 测试目标 |
|:---:|:---:|:---:|
| 50% | 前半部分 | 指纹是否还能溯源 |
| 25% | 前半部分 | 指纹是否还能溯源（极限测试） |

**为什么截断反而可能增加分离度？** 截断越严重，两家族的 MAD 都增大（信息少了，指纹估计更不稳），但增长是**同向不等量**的——Qwen 指纹漂移（0.040→0.050）小于 GPT-2（0.079→0.097），因为 Qwen 的 β 剖面更"平坦稳定"，对 token 数不敏感。因此分离度反而从 0.039 升至 0.047。

## ④ 推导过程

**Step 1 — 截断的统计效应。** 指纹中逐深度 β 剖面是对该层 token 激活的能量集中度的估计。保留 `k = r·T` 个 token 时，估计量的统计噪声 $\propto 1/\sqrt{k} = 1/\sqrt{rT}$。截断越狠（r 越小），噪声越大 → MAD 单调增大。这是 25% 比 50% MAD 更大的机制。

**Step 2 — 为什么 Qwen 漂移小于 GPT-2。** 两家族对截断的响应差异源于 β 剖面结构：Qwen 的逐层 β_max 剖面平缓（信息沿深度均匀），截断掉后半段 token 只引入均匀噪声；GPT-2 剖面陡峭，截断导致估计更不稳定。实测分离度随截断加深：

| 截断比例 | MAD(Qwen) | MAD(GPT-2) | 分离度 | 溯源准确率 |
|:---:|:---:|:---:|:---:|:---:|
| 100%（无截断） | 0.040 | 0.079 | 0.039 | 100% |
| 50% | 0.042 | 0.085 | 0.043 | 100% |
| 25% | 0.050 | 0.097 | 0.047 | 100% |

**Step 3 — 家族判定不受截断影响。** 溯源判定比较的是 `MAD 到 Qwen 簇` vs `MAD 到 GPT2 簇`。截断使两者同时增大（同向），但 Qwen 的增量为 `+0.010`、GPT-2 的增量为 `+0.018`，相对差距未反转 → 判定边界稳定，溯源准确率保持 100%。

## ⑤ 数值验证

- **实测值**：`trunc_25%` 时 `MAD(Qwen)=0.050`、`MAD(GPT-2)=0.097`、分离度 `0.047`、溯源准确率 `100%`。
- 关键结论：截断程度不影响家族判定，只增加指纹与基线的绝对距离。
- 验证脚本 [verify.py](verify.py)：合成 token 激活矩阵（T=96），提取 24 维 β 剖面；按 50%/25% 截断重算指纹；复现 MAD 递增、Qwen 漂移 < GPT-2 漂移、分离度递增（0.039→0.047）与溯源 100% 的比对逻辑。**合成数据仅验证算法逻辑，数值对齐实测量级。**
