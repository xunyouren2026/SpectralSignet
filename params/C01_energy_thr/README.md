## ① 定义

`C01 energy_thr` 定义主成分能量累积的**截断阈值**，固定为 **0.90（90%）**。

激活矩阵 `H ∈ ℝ^{B×d}` 的协方差矩阵特征值 `λ₁ ≥ λ₂ ≥ ... ≥ λ_d` 降序排列。`energy_thr=0.90` 表示：找到**最小**的 k，使得前 k 个主成分累积能量占总能量的 90% 以上。

```python
C01 energy_thr = 0.90    # 固定值
```

`k90` 越小 → 激活越"集中"，信息被压缩在少数方向，模型几何结构越紧致。`energy_thr` 是衡量模型**可压性**的核心标尺（主文档行 1752-1762）。

**默认/实测范围**：`0.90`（状态：理论，作为 KV 可压缩性预测的默认阈值）。

---

## ② 公式

k90 的定义（主文档行 1748）：

$$k_{90} = \min\left\{k : \frac{\sum_{i=1}^{k}\lambda_i}{\sum_{i=1}^{d}\lambda_i} \ge 0.90\right\}$$

- 协方差：`cov = HᵀH/(B-1)`，特征值 `eigvals = np.linalg.eigvalsh(cov)[::-1]`（降序）
- 累积能量占比：`cumsum = np.cumsum(eigvals)/np.sum(eigvals)`
- `k90 = np.argmax(cumsum >= 0.90) + 1`

导出量（KV 压缩比，输出指标 106）：

$$\text{compression\_ratio} = \frac{d}{k_{90}} = \frac{\text{head\_dim}}{k_{90}}$$

信息论含义：保留 90% 能量（方差）≈ 几乎无损保留主要信息（主成分分析的主成分累积方差解释度；Jolliffe, 2002）。

## ③ 物理/几何直觉与用途

**物理直觉**：模型每一层的激活是流形上的点集。协方差谱刻画"能量在各方向上的分布"——谱越陡（少数大特征值），流形越**低秩/扁平**；谱越平，流形越**高维弥散**。`k90` 就是这个流形"在几乎无损条件下能压到多少维"的答案。

**几何直觉**：`k90` 与 B01/C-子空间（前 M=3 主方向）直接对应——`k90` 是"信息论意义上的有效子空间维数"，γ（`101 spl_gamma`）是几何意义上的集中度。两者量纲不同但方向一致：k90 小 ⟺ γ 高。

**用途**（主文档行 1754-1811）：
1. **可压性标尺**——k90<10 高度可压、10-30 中等、>50 弥散不可压；
2. **KV 缓存压缩基准**——`head_dim/k90` 给出理论压缩比，Qwen k_proj 达 68.9×；
3. **预测 KV 可压缩性**——压缩策略默认 `energy_thr=0.90`；
4. **跨投影排序**——k_proj 的 k90(13) ≪ up_proj 的 k90(64)，是 β 排序的工程对应。

## ④ 推导过程

**第 1 步：谱分解。** 锚定层激活 `H∈ℝ^{B×d}`，去均值后协方差 `C = HᵀH/(B-1)`，对 C 做特征分解得特征值谱 `{λᵢ}`。

**第 2 步：能量归一化。** 令 `E_k = Σ_{i≤k}λᵢ / Σ_{i=1}^{d}λᵢ`，`E_k` 单调不减，`E_d = 1`。

**第 3 步：定义解。** `k90 = min{k : E_k ≥ 0.90}`。由于 `E_k` 阶梯单调，解唯一且满足：

$$\sum_{i<k_{90}}\lambda_i < 0.90\sum_i\lambda_i \;\le\; \sum_{i\le k_{90}}\lambda_i$$

**第 4 步：阈值扫描性质。** `k90(thr)` 关于 thr 单调不减：`0.50→6, 0.90→13, 0.95→18, 0.99→35`（Qwen k_proj，主文档行 1793-1798）——阈值越高需保留主成分越多，压缩比越小。

**第 5 步：工程导出。** KV 缓存每 token 字节 `KV = 2L·n_kv·head_dim·4`；谱压缩理论下限 `head_dim/k90`。Qwen k_proj：`896/13 = 68.9×`，即 KV 可压缩到 1/69 而不损失 90% 信息。
