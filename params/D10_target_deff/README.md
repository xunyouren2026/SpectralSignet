# D10 target_deff — 平台反解目标

> 组：D 统计/裁决 | 状态：✅ 已用 | 数据源：主文档行 3074-3207、《参数完整定义与公式.txt》行 228-235、《参数审计与实验报告.txt》行 61、109、140、154

## ① 定义

`D10 target_deff` 定义反解闭环的目标 DEFF 值，**两个取值**：

- **1.5711**：NS 湍流饱和态的有效维度平台值（从 DNS 数据得到）；
- **1.5920**：AI 推理过程中的有效维度实测值（Qwen 0.5B 生成 DEFF 实测均值）。

在反解闭环中，`D09 lam_grid` 建立 λ→E[DEFF] 映射表，`target_deff` 指定一个目标 DEFF，系统反查映射表得到对应 λ\*：

$$\lambda^* = f^{-1}(\text{DEFF}_{target})$$

**为什么是这两个值？** 两者相差 0.0209（约 1.3%）——非常接近，但 AI 侧略高于 NS 平台，说明 AI 的几何锁定尚未完全达到 NS 的精度（审计报告行 10：Hmed=1.3152 未趋 0，链长需更长）。

---

## ② 公式

```python
target_deff_ns = 1.5711    # NS 饱和态平台
target_deff_ai = 1.5920    # AI 实测

f_reverse = 插值(E[DEFF]_lookup, λ_grid)      # D09 映射反查
lambda_star_ns = f_reverse(1.5711)
lambda_star_ai = f_reverse(1.5920)
```

闭环对比（D11 判据，15%）：

$$\text{偏差} = \frac{|\lambda^* - \lambda_{\text{实测}}|}{\lambda_{\text{实测}}} < 15\%$$

## ③ 物理/几何直觉与用途

**物理直觉**：DEFF=1.57-1.59 是"鞍面主导型流形"的有效维数平台——κ₁、κ₂ 幅度接近但不等（λ≈0.85），DEFF 落在 1.5-1.6 区间。NS 湍流与 AI 激活流形落在同一平台 → 跨域几何同构的定量证据。

**几何直觉**：反解 λ\* 是"由 DEFF 平台反推曲率幅度各向异性比"的操作。如果模型正确，λ\* 应与直接实测的 λ（std 比）一致。

**用途**：`D10` 是反解闭环的**目标设定**：验证"DEFF 平台 → λ"的反向推理是否自洽。**⚠️ 实测审计**：在"各向异性高斯"底层模型下，反解 λ\*≈0.41-0.52，与实测 λ=0.852 偏差 ≈40-48% > 15% → **未闭环**（审计报告行 140、154），该底层模型应替换为"鞍形+解耦"模型。

**第三步（行 3141-3160）：与实测 λ 对比。** 主文档叙述：NS 偏差 0.16%，AI 偏差 6.86%，均 <15% → 闭环成立。

**第五步（行 3172-3182）：物理含义。** DEFF≈1.57 → σ₂/σ₁≈0.85 → 鞍面主导特征值。

**⚠️ 重要审计（主文档叙述 vs 真实 MC）**：D09 的闭式与 MC 验证表明，各向异性高斯模型中 E[DEFF] 的范围是 [1, 1+2/π≈1.6366]，反解 1.5711 → λ\*≈0.44、1.5920 → λ\*≈0.52（**注意 λ\*_AI < λ\*_NS 而非主文档的 0.910>0.853**，因为 E(λ) 单调增、目标值越大 λ\* 越大，1.5920>1.5711 应给更大 λ\*——主文档 0.853/0.910 的数值排序也与映射单调性不符）。真实结果与实测 λ=0.852 偏差 ≈40-48%>15% → **未闭环**，与审计报告 T06 完全一致。`verify.py` 输出真实 MC 反解结果。
