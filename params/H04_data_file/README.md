## ① 定义

`H04 data_file` 定义版本 A 曲率分析的数据文件路径，固定为 `phi_pairs_all.npy`。文件存储逐点的主曲率对 $(\kappa_1,\kappa_2)$，共 **6303** 个样本点，形状 `(6303, 2)`，dtype float64。每一行是曲率采样在某帧某层上的一个点的主曲率值，用于 φ 分布分析与 M1-M4 模型拟合。

```python
import numpy as np
data = np.load('phi_pairs_all.npy')  # (6303, 2)
kappa1, kappa2 = data[:, 0], data[:, 1]
```

**为什么是 6303 个点**：版本 A 曲率采样在各帧各层聚合后的总点数，由采样参数（B05/B06 等）共同决定。该数量足够稳定 χ² 拟合（M3 截断高斯 p=0.91），又不会过大导致计算冗余。

## ② 公式

数据集驱动的下游指标：

$$\varphi = \arctan\frac{|\kappa_2|}{|\kappa_1|}\in[0,45^\circ]\quad(\text{约定 }|\kappa_1|\ge|\kappa_2|)$$

$$\text{DEFF} = \frac{(|\kappa_1|+|\kappa_2|)^2}{\kappa_1^2+\kappa_2^2}\in[1,2]$$

$$\lambda = \frac{\sigma(\kappa_2)}{\sigma(\kappa_1)}\quad(\text{曲率幅度尺度比})$$

$$K_{<0}\% = 100\cdot\text{mean}[\kappa_1\kappa_2<0]\quad(\text{负 Gauss 曲率占比})$$

## ③ 物理/几何直觉与用途

**物理直觉**：主曲率对 $(\kappa_1,\kappa_2)$ 是流形局部几何的完整描述——Gauss 曲率 $K=\kappa_1\kappa_2$ 与平均曲率 $H=(\kappa_1+\kappa_2)/2$ 都由其决定。该数据集是"激活流形曲率身份"的**原始观测**：6303 个点刻画流形上鞍点/椭球点/圆柱点的分布、主方向比与幅度耦合。**比值型指标（DEFF、φ、λ）对公共能量尺度免疫**——这是抗微调/抗重生成溯源的关键特性。

**用途**（整个 φ 分布分析体系的数据源）：

| 下游分析 | 输入 | 输出 |
|---|---|---|
| φ 角计算（D01） | (κ₁,κ₂) | φ 分布直方图 |
| M1-M4 模型拟合（D02-D07） | φ 分布 | 最优分布模型（M3 截断高斯） |
| DEFF 计算（202） | (κ₁,κ₂) | DEFF=(|κ₁|+|κ₂|)²/(κ₁²+κ₂²) |
| 闭环验证（D09-D11） | (κ₁,κ₂) | λ=σ₂/σ₁，反解闭环 |

## ④ 推导过程

**推导 1：φ 的排序约定**。主曲率按绝对值排序 $|\kappa_1|\ge|\kappa_2|$，则 $\varphi=\arctan(|\kappa_2|/|\kappa_1|)\in[0,45^\circ]$。各向同性流形（两主曲率幅度统计相等）→ φ 期望 $22.5^\circ$；实测 φ 均值 $20.26^\circ$ 略低，反映轻微各向异性。

**推导 2：DEFF 的不变量性质**。设 $(|\kappa_1|,|\kappa_2|)\to(A|\kappa_1|,A|\kappa_2|)$（公共尺度 $A$ 扰动）：

$$\text{DEFF} = \frac{(A|\kappa_1|+A|\kappa_2|)^2}{A^2\kappa_1^2+A^2\kappa_2^2} = \frac{(|\kappa_1|+|\kappa_2|)^2}{\kappa_1^2+\kappa_2^2}$$

即 DEFF 对公共尺度 $A$ 完全不变（E07 实测平台漂移≈0），这正是"比值型指纹"抗扰动的数学根源。

**推导 3：DEFF 平台 = π/2**。设两主曲率幅度为独立各向同性量，则 $\varphi$ 在 $[0,45^\circ]$ 均匀分布，$E[\text{DEFF}] = E[1+\sin 2\varphi] = 1 + \frac{2}{\pi}\int_0^{\pi/2}\sin 2\varphi\,d\varphi \cdot \frac{2}{\pi}...$ 实际平台 $\approx \pi/2 = 1.5708$（实测 1.5920，偏差 1.35%，见 T01）。
