## ① 定义

`D03 θ_grid` 定义 M2 模型（截断均匀分布）最优截断角 θ 的搜索网格：**从 25° 到 45°，步长 0.2°**。M2 假设 φ 分布在 `[0, θ]` 上均匀、`(θ, 45°]` 上概率为 0：

$$p(\phi) = \begin{cases} \dfrac{1}{\theta}, & 0 \le \phi \le \theta \\[4pt] 0, & \theta < \phi \le 45° \end{cases}$$

θ 是待估计的截断角。`θ_grid` 在 25°-45° 内网格搜索，取使 χ² 最小的 θ*。

**为什么是 25°-45°？** θ<25° 意味着分布极度集中在低角度（实际数据中罕见，实测峰值≈20° 不会在 20° 处突然截断）；θ>45° 即全范围均匀、与 M1 等价。该网格的意义主要是**确认 M2 不适用**，从而支持 M3（截断高斯）。

---

## ② 公式

截断均匀期望频数（源码 `exp_trunc`）：

```python
def exp_trunc(theta):
    c = np.clip(hi, 0, theta) - np.clip(lo, 0, theta)   # bin 落在 [0,θ] 内的宽度
    return N * c / theta                                 # 均匀密度 1/θ
```

最优搜索：

```python
thetas = np.arange(25.0, 45.01, 0.2)      # D03 θ_grid
chi2_min = inf
for theta in thetas:
    c2, dof = chi2_merge(obs_fit, exp_trunc(theta))
    if c2 < chi2_min: best = (theta, c2, dof)
```

判决：`θ*→45°` 则 M2 退化接近 M1（全均匀）；`θ*` 显著 <45° 才有独立意义。

## ③ 物理/几何直觉与用途

**物理直觉**：M2 回答"φ 分布是否在某角度 θ 处被硬截断"。如果流形在某个 φ 角以上完全不存在点，说明存在一个几何上的"截止方向"。

**几何直觉**：
- `θ=45°`：全范围均匀 ⇔ 完全各向同性（等价 M1）；
- `θ≈35°`：35° 内均匀、尾部为空 → 中等各向异性；
- `θ≈25°`：分布集中在低角度 → 鞍面主导、各向异性；
- `θ≈15°`：高度集中低角度 → 管状主导。

**用途**：实测中 M2 从未胜出（p 值低），最优 θ*≈43.5° 逼近 45°——说明 φ 分布不呈"硬截断均匀"形态，为 M3（截断高斯）的胜出提供对照证据。

## ④ 推导过程

**第一步（行 2186-2191）：构建 D01 直方图。**

**第二步（行 2193-2212）：对每个 θ∈θ_grid 计算 M2 期望频数。** 只有 `φ_center ≤ θ` 的格点有概率 `total/θ × 0.5`，其余为 0；只对 `expected>1` 的格点算 χ²。

**第三步（行 2214-2221）：取 χ² 最小的 θ\*。**

**第四步（行 2223-2233）：θ 扫描表。** 实测 θ=25° χ²=78.5 → 30° 62.3 → 35° 55.1 → 40° 52.8 → 45° 51.2（接近 M1）。最优 θ≈45°，**M2 趋向 M1**。

**第五步（行 2235-2242）：与 M3 对比。** M2 最优 θ=43.5°, χ²=51.2, p=0.45；M3 最优 μ=14.1°, σ=25.1°, χ²=42.1, p=0.91。**M3 的 χ² 显著更低 → M2 否决**。
