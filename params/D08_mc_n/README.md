## ① 定义

`D08 mc_n` 定义 M1-M4 模型拟合时理论分布生成的蒙特卡洛采样次数，**固定为 400000**。χ² 拟合需要将理论分布（连续函数）与实测 φ 直方图（有限样本）对比，理论期望频数：

$$E_i = N \cdot \int_{bin_i} p(\phi)\, d\phi$$

M3 截断高斯积分无简单解析形式（虽可用 erf），采用 MC：从理论分布采样 `mc_n` 个点，统计落入各格的占比，乘总样本数得期望频数。

**为什么是 400000？** MC 采样误差 ∝ $1/\sqrt{mc\_n}$。400000 → 期望频数统计波动 ≈ $1/\sqrt{400000}\approx0.16\%$，对 χ² 影响 <0.01；而 mc_n=10000 时波动 ≈1%，χ² 波动 ±2-3，可能改变拟合结论。实测：增加到 1000000，χ² 变化 <0.02，但计算时间 +2.5 倍。

---

## ② 公式

```python
mc_n = 400000                       # D08
phi_mc = np.random.normal(mu, sigma, mc_n)     # 高斯采样
phi_mc = phi_mc[(phi_mc>=0) & (phi_mc<=45)]    # 截断[0,45]
# 拒绝采样补充至 mc_n（源码 _phi_fit_chi2 亦用解析 erf 路径）
counts_mc, _ = np.histogram(phi_mc, bins=bins)
expected = counts_mc / mc_n * N_total           # MC 期望频数
```

MC 统计误差（逐格占比）：

$$\sigma_{E_i} \approx \frac{1}{\sqrt{mc_n \cdot p_i}},\qquad \sigma_{\chi^2} \sim \frac{1}{\sqrt{mc_n}}$$

## ③ 物理/几何直觉与用途

**物理直觉**：理论分布是连续概率，观测是离散直方图。MC 是"用随机模拟估计积分"的通用方法——样本越多，估计越接近真实积分，χ² 越稳定、p 值越可靠。

**几何直觉**：φ 分布的理论期望频数必须与实测直方图"同尺度可比"。mc_n 太小 → 期望频数有锯齿噪声 → 即使模型正确也会被判"不拟合"；mc_n=400000 使期望频数平滑到足以分辨真实的拟合优度。

**用途**：`D08` 是所有模型（M1-M4）χ² 拟合的**精度保证**，也用于 D09 的 λ→E[DEFF] 映射模拟（MC 400000，主文档行 2983）。实测 mc_n=400000 下 M3 拟合 χ²=42.1, **p=0.91**。

## ④ 推导过程

**第一步（行 2871-2888）：从理论分布生成 MC 样本。** 高斯采样 → 截断 `[0,45]` → 拒绝采样补充到 mc_n。

**第二步（行 2890-2900）：统计期望频数。** `counts_mc` 与 D01 bins 对齐；`expected = counts_mc/mc_n × N_total`。

**第三步（行 2902-2906）：计算 χ²（D02 拟合域内）。**

**第四步（行 2908-2917）：MC 采样数对 χ² 稳定性的影响。**

| mc_n | χ² | p 值 | 波动 |
|------|-----|------|------|
| 10000 | 43.5 | 0.82 | ±2.0 |
| 50000 | 42.8 | 0.87 | ±0.8 |
| 400000 | 42.1 | 0.91 | ±0.05 |
| 1000000 | 42.0 | 0.91 | ±0.02 |

400000 时 χ² 基本稳定；增至 1e6，χ² 变化 <0.02 而耗时 +2.5 倍 → 400000 为最优平衡点。

**第五步（行 2919-2933）：产出。** 结论：400000 足够稳定，固定 mc_n=400000。
