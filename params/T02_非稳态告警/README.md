## ① 定义

`T02 非稳态告警` 是 DEFF **帧间波动**告警（时间型告警），测量流形在时间演化上的**几何稳定性**。它以 DEFF 帧序列的变异系数（Coefficient of Variation, CV）是否超过 `3%` 作为判据：

- CV ≤ 3% → **稳态**（几何锁定，无需干预）
- CV > 3% → **非稳态**（几何漂移，需关注）

实测状态：**白盒 CV = 1.07% ✓**（8 帧 DEFF 序列的标准差仅为均值的 1.07%，远低于 3% 阈值）

## ② 公式

$$\text{CV} = \frac{\text{std}(DEFF)}{\text{mean}(DEFF)} \times 100\%$$

$$\text{Alert} = \text{CV} > 3\%$$

| CV 范围 | 状态 | 判读 |
|---------|------|------|
| < 1% | 极稳 | 几何结构近乎恒定 |
| 1% – 3% | 稳定 | 自然波动（白盒实测 1.07%） |
| 3% – 5% | 警告 | 几何开始漂移（需关注） |
| > 5% | 危险 | 表示退化，可能崩溃 |

## ③ 物理/几何直觉与用途

T02 回答的问题是「**流形在时间上是否平稳**」，与 T01（均值偏离）正交：

- 一组帧的 DEFF 均值可以在平台内，但如果帧间**波动过大**，说明推理过程中的几何结构在漂移——这对应推理早期/瞬态/退化阶段。
- **跨域同构意义**：NS 饱和态 CV ≈ 0.25%（极稳），AI 白盒 8 帧 CV ≈ 1.07%（稳定），AI 短链 12 帧 CV ≈ 1.5%（稳定）。AI 与 NS 的几何锁定精度处于同一量级（均 < 2%），构成「跨域几何同构」的证据链。
- **用途**：实时监控面板自动判定推理过程是否平稳。CV 由 `202 DEFF_A` 的帧序列直接计算。

## ④ 推导过程

**Step 1 — 变异系数的选择。** 相比标准差本身，CV = std/mean 是**无量纲**的归一化波动量，可跨模型、跨链长直接比较（DEFF 平台值不同模型略有差异，CV 消除该偏置）。

**Step 2 — 3% 阈值的量级论证。** 已知锚点：

| 对象 | CV |
|------|----|
| NS 饱和态 | ≈ 0.25% |
| AI 白盒 8 帧 | ≈ 1.07% |
| AI 短链 12 帧 | ≈ 1.5% |

`3%` 约为 AI 实测波动（1.07%）的 2.8 倍，为 NS 的 12 倍——足以区分「自然波动」与「结构漂移」，同时避免对短链正常波动过度告警。

**Step 3 — 白盒 8 帧实测计算。** 采用精确 8 帧序列（`_verify_deff_pi_over_2.py`）：

```
DEFF_seq = [1.5922, 1.5855, 1.5812, 1.5795, 1.5446, 1.5517, 1.5646, 1.5902]
mean = 1.5737   std = 0.01680（总体标准差）
CV = 0.01680 / 1.5737 × 100% = 1.07%  <  3%   →  稳态 ✓
```
