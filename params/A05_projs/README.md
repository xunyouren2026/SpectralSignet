## ① 定义

`A05 projs` 指定要监控哪些**投影类型**——模型内部哪些线性变换的输出被纳入指纹计算。默认 `(k_proj, up_proj, o_proj)`（主文档行 339）。

7 种投影及其模块归属（主文档行 327-337）：

| 投影类型 | 所属模块 | 功能 |
|----------|----------|------|
| k_proj | Attention | Key 投影，计算注意力权重 |
| q_proj | Attention | Query 投影，查询 |
| v_proj | Attention | Value 投影，提取值 |
| o_proj | Attention | Output 投影，注意力输出线性变换 |
| gate_proj | MLP | 门控投影（SwiGLU 等） |
| up_proj | MLP | 上投影，特征扩增 |
| down_proj | MLP | 下投影，特征压缩 |

```python
projs = ("k_proj", "up_proj", "o_proj")   # 默认（标准指纹）
projs = ("k_proj",)                        # 单投影（快速验证）
projs = ("k_proj","q_proj","v_proj","o_proj","gate_proj","up_proj","down_proj")  # 全投影
```

**默认/实测范围**：`k/up/o`（+q/v/gate/down），已用。

## ② 公式

```
A05 := tuple[str, ...] ∈ {k,q,v,o,gate,up,down}_proj
指纹维度 = N_layers × |A05|
  三投影: 24 × 3 = 72 点
  全投影: 24 × 7 = 168 维
```

各投影的谱集中度（Gamma，主文档行 345-353 / 397-405）：

| 投影 | 实测 Gamma | 物理含义 |
|------|-----------|----------|
| o_proj | 0.78 | 注意力输出通道最集中 |
| k_proj | 0.72 | Key 投影最集中→最耐压 |
| q_proj | 0.68 | 适中 |
| gate_proj | 0.67 | 门控，较弥散 |
| down_proj | 0.64 | 压缩，弥散 |
| v_proj | 0.63 | 较弥散 |
| up_proj | 0.60 | 最弥散→最不耐压 |

Gamma 定义（B01/M 谱集中度）：$\gamma = \sum_{i\leq M} s_i^2 / \sum_i s_i^2, \quad M=3$

## ③ 物理/几何直觉与用途

**物理直觉**：不同的投影是信息流经 Transformer 的"不同通道"。注意力（Attention）通道负责上下文混合，MLP 通道负责特征变换。几何上，不同通道的激活在 C-子空间的能量集中程度不同——o/k 最集中（低秩、耐压），up 最弥散（高维展开、不耐压）。

**几何直觉**：选择 projs = 选择"从哪个几何角度观察模型"（主文档行 439）：
- 只选 `k_proj` → 指纹反映"注意力集中度"；
- 只选 `up_proj` → 指纹反映"MLP 弥散度"；
- 多投影联合 → 多投影联合的"几何全景图"。

**用途**（主文档行 409-417）：
1. **快速验证（10 秒级）**：`(k_proj,)`——最轻量，k_proj 最集中、信息量最大；
2. **标准指纹（1 分钟级）**：`(k_proj, up_proj, o_proj)`——覆盖三个代表性投影；
3. **完整指纹（3 分钟级）**：全 7 投影——最全几何画像；
4. **水印嵌入**：`(k_proj,)`——只在 k_proj 做投影，计算开销最低；
5. **曲率特征**：`(k_proj, up_proj, o_proj)`——版本 A 曲率计算需要多投影联合。

## ④ 推导过程

完整操作流程（主文档行 361-437）：

1. **默认配置**（行 363-371）：`(k_proj, up_proj, o_proj)` → 3×24=72 激活点指纹。
2. **单投影调试**（行 373-381）：`(k_proj,)` → 24 维指纹，验证"k_proj 是否真的最集中"。
3. **全投影扫描**（行 383-391）：7 投影 → 7×24=168 维完整指纹。
4. **投影对比分析**（行 393-407）：逐投影记录 Gamma，得到排序 o(0.78)>k(0.72)>q(0.68)>down(0.64)>v(0.63)>gate(0.67)>up(0.60)。该排序 = 模型"投影级几何指纹"，跨输入稳定、跨模型可对比。
5. **策略选择**（行 409-417）：见 ③ 用途表。
6. **报告**（行 419-437）：输出各投影 Gamma 表 → 结论"o_proj 最集中，up_proj 最弥散——与 β 谱测量一致"。

**审计报告实测（行 20-28，3 prompts × 24 层均值）**：
```
o_proj 0.7765 > k_proj 0.7227 > q_proj 0.6812 > gate_proj 0.6648
> down_proj 0.6428 > v_proj 0.6311 > up_proj 0.6009
```
排序：o > k > q > gate > down > v > up。

## ⑥ 与关联参数的关系

| 关联参数 | 关系 |
|----------|------|
| A01 model | 投影挂到具体模型的层上；Qwen 的层名含 self_attn./mlp. 前缀 |
| A04 layer_names | 层名 = `model.layers.{i}.{模块}.{proj}`，与投影类型组合成钩子名 |
| B01 M | Gamma = 前 M=3 主成分能量占比，投影的谱集中度度量 |
| B10 anchor | 锚定 `layer12.k_proj`——中间层 k_proj 是 β_t 实时追踪对象 |
| B05/B07 | 曲率特征需多投影联合（k/up/o） |
| A06 三实例路径 | 指纹维度由 A05 决定，三实例参考库按同一 projs 计算 |
| E 组扰动 | 扰动测试在同一 projs 下进行，验证投影级指纹鲁棒性 |
