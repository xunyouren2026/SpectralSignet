## ① 定义

`T07 谱门控增强` 是 `SpectralCognitionPlugin` 中谱门控功能的**数学操作定义**（阈值/常量组中的「操作公式」型参数）。它定义如何将激活向量 `H` 沿 C-子空间方向「拉」比例 `s`，以增强低秩结构、抑制高阶弥散：

- `s = 0.0`：纯检测模式（不修改激活）
- `s = 0.3`：标准增强模式（推荐值，`G01 gate_strength`）
- `s > 0.5`：激进增强（可能改变输出分布）

实测状态：**设计**（公式已在 [`spectral_gating.py`](file:///c:/Users/小冰/Desktop/宇宙/AIQ/spectral-cognition/modules/spectral_gating.py) 实现，未系统验证；Qwen 0.5B 上 s=0.3 时 Gamma 从 0.17 提升至约 0.19-0.23）

## ② 公式

$$H_{\text{gated}} = H + s \cdot (\Pi_C H - H)$$

其中：
- `H`：原始激活向量
- `Π_C H`：将 `H` 投影到 C-子空间的分量（低秩部分：n=0 常数模态 = 均值 μ，n=1 偶极模态 = 第一主方向 v₁，n=2 四极模态 = 第二主方向 v₂）
- `H − Π_C H`：激活的补空间分量（高阶弥散部分）
- `s`：门控强度（`G01 gate_strength`）

等价形式：

$$H_{\text{gated}} = (1-s)\,H + s\,\Pi_C H$$

**物理含义**：将激活沿 C-子空间方向「拉」s 比例——`s=0` 无操作，`s=1` 完全投影到 C-子空间（论文 H-消融，实验五显示性能保持 93-99%）。

## ③ 物理/几何直觉与用途

- **C-子空间的几何意义**：C-子空间承载因果决策的核心低阶模态（均值方向 + 前两个主成分方向）。增强它 = 让模型聚焦核心几何方向；抑制补空间 = 去掉高阶冗余噪声。
- **谱集中度提升**：门控后前 M=3 个主成分的能量占比（Gamma）上升——这正是 Qwen 0.5B 上 s=0.3 时 Gamma 从 0.17 提升至 0.19-0.23 的机制。
- **用途**：推理时在线增强激活几何集中度，作为插件钩子（与 G 组挂钩参数配合）在 forward 中替换原始激活。
- **边界**：s 过大（>0.5）可能改变输出分布（过度压缩补空间信息），工程上以 s=0.3 为推荐折中。

## ④ 推导过程

**Step 1 — C-子空间投影。** C-子空间的工程近似（源码 [`spectral_gating.py`](file:///c:/Users/小冰/Desktop/宇宙/AIQ/spectral-cognition/modules/spectral_gating.py) 行 7-14）：n=0 常数模态 → 激活均值方向 μ；n=1 偶极 → 第一主成分 v₁；n=2 四极 → 第二主成分 v₂。对去均值激活 `H_c = H − μ` 做主成分分解（SVD），投影为：

$$\Pi_C H = \mu + (H_c V) V^{\top}, \qquad V = [v_1, v_2] \in \mathbb{R}^{d \times 2}$$

**Step 2 — 门控线性插值。** 门控是原始激活 `H` 与投影 `Π_C H` 的凸组合：

$$H_{\text{gated}} = (1-s)\,H + s\,\Pi_C H$$

- `s=0`：返回 H（检测模式）；
- `s=1`：完全投影到 C-子空间（论文 H-消融）；
- `s∈(0,1)`：部分增强，保留补空间信息 `(1−s)(H−Π_C H)`。

**Step 3 — 正交分解。** `H = Π_C H + (H − Π_C H)`，且 `Π_C H ⊥ (H − Π_C H)`（投影算子的性质）。门控等效于在低秩分量上乘 `1·`、在补空间分量上乘 `(1−s)`：

$$H_{\text{gated}} = \underbrace{\Pi_C H}_{\text{低秩, 保留}} + (1-s)\,\underbrace{(H - \Pi_C H)}_{\text{高阶弥散, 压缩}}$$

**Step 4 — 谱集中度（Gamma）随 s 单调不减。** 定义 `Γ = 前 M 个主成分能量占比`。因门控压缩补空间分量、放大低秩占比，`Γ(s)` 随 s 单调不减，且 `Γ(1) = 1`（完全投影到 3 维子空间时前 3 主成分占比为 1）。Qwen 0.5B 上 `Γ: 0.17 → 0.19-0.23 (s=0.3)` 即此机制。
