## ① 定义

`D01 bins` 定义主曲率角 φ 分布的直方图分格方式：**0° 到 45°，共 46 格**（文档口径"每 0.5° 一格"）。它把每个采样点的一对主曲率 `(κ₁, κ₂)`（约定 `|κ₁| ≥ |κ₂|`）压缩成单个角度：

$$\phi = \arctan\left(\frac{|κ₂|}{|κ₁|}\right) \in [0°, 45°]$$

- `φ=0°`：κ₂≈0，圆柱面 / 管状结构（一维主导）；
- `φ=45°`：|κ₁|=|κ₂|，各向同性鞍面（二维主导）；
- `φ∈(0°,45°)`：椭圆点或鞍点的中间状态。

分格实现（主文档行 1992）：`bins = np.arange(0, 46.5, 0.5)`（**注：该示例代码实际生成 92 格**，见下方审计）；源码 `_phi_fit_chi2.py` 行 87 实际用 `bins = np.linspace(0, 45, 46)`（45 格、每格 1°）。

**为什么是 0-45° 而不是 0-90°？** 因为 `|κ₁| ≥ |κ₂| ⇒ |κ₂|/|κ₁| ∈ [0,1]`，故 `φ = arctan(比值) ∈ [0,45°]`。45° 是"各向同性"分界：比值=1。

**为什么格宽要精细？** φ 分布拟合出的高斯峰宽约 25°（D05），0.5° 级分辨率足以解析峰形；过细（0.1°）则统计噪声主导。

---

## ② 公式

$$\phi = \arctan\left(\frac{\min(|κ₁|,|κ₂|)}{\max(|κ₁|,|κ₂|)}\right),\qquad \phi \in [0°, 45°]$$

直方图分格：

```python
phi_deg = np.degrees(np.arctan2(np.abs(κ2), np.abs(κ1)))   # [0,45]
counts, edges = np.histogram(phi_deg, bins=np.linspace(0, 45, 47))  # 46格
# 源码实际口径：bins=np.linspace(0,45,46) → 45格
```

格心：`edges[:-1] + 格宽/2`（0.25°, 0.75°, …, 44.75°）。分格后 χ²、BIC 等统计检验（M1-M4 四模型拟合）才可计算。

---

## ③ 物理/几何直觉与用途

**物理直觉**：φ 是"两主曲率幅度之比"的角度编码，衡量流形在每个采样点的主方向各向异性。鞍面主导流形（K%≈40-57%）在主曲率比上呈现特征分布：峰值在 14° 附近（D04），即第二主曲率约是第一主曲率的 `tan14°≈0.25`，说明 κ₁、κ₂ 幅度不等、符号相反。

**几何直觉**：
- φ 分布**均匀** → 各向同性随机流形（如随机数据，φmean≈22.5°）；
- φ 分布**单峰高斯（μ≈14-20°, σ≈25°）** → 鞍面主导流形（Qwen/GPT-2 实测）；
- φ≈0° 处**异常尖峰** → 管状主导（数值伪影或真实结构，由 D06/D07 检验）。

**用途**：`D01` 是 M1-M4 四模型拟合的**输入直方图**，直接控制分析分辨率与统计可靠性，也是 `D02 fit_range` 的裁剪对象。

## ④ 推导过程

**第一步（主文档行 1941-1947）：φ 定义域推导。** 曲率排序保证 `|κ₁| ≥ |κ₂|`，因此：

$$\frac{|κ₂|}{|κ₁|} \in [0, 1] \;\Rightarrow\; \phi = \arctan(\text{比值}) \in [0°, 45°]$$

**第二步（行 1953-1955）：分格数选取。** 0.5° 格在 45° 内产生 46 格（文档口径），保留分布形状细节且不放大噪声；对照 1° 格（45 格）偏粗、0.2° 格（225 格）噪声主导。

**第三步（行 1980-2005）：逐点 φ 入直方图。** 对每个采样点计算 φ → `np.histogram` → 得到 `counts[46]`。实测峰值在 φ≈20° 附近（φmean=20.26°，审计报告行 11），符合"鞍面主导"。

**第四步（行 2021-2028）：分布形态判据。** 均匀 / 单峰高斯 / 双峰 / 尖峰 四类 → 对应不同流形类型。

运行 `python verify.py`（纯数值合成数据，不加载大模型）。

| 验证项 | 预期 | 结果 |

| 合成截断高斯 N(14°,25°)\|[0,45] 峰值格 | 峰值格心 ≈ 14° | 见脚本输出 |
| 合成数据 φ 均值 | ≈ 20.26°（实测） | 见脚本输出 |

**实测值引用**（来自数据源，非脚本产生）：
- φ 分布 `N(14°,25°)` 截断 `[0,45°]`，M3 胜出 **p=0.91**（审计报告行 17、规格行 578）；
- φ 均值/中位数 **20.26° / 19.75°**（审计报告行 11，各向同性→22.5°）；
- 分格状态 **已用**（审计报告行 52）。

**误差说明**：合成数据由截断高斯采样生成，φ 均值/峰值与实测（μ=14.1°, σ=25.1°）的偏差来自采样统计波动（n=2e5 时约 ±0.1°）；脚本只校验分格算法逻辑，不声称复现真实曲率测量。

**⚠️ 审计发现（文档-源码不一致）**：
- 主文档行 1939/1953 声称"0-45° **46 格**、**每 0.5° 一格**"——数学上 0-45°@0.5° 应为 **90 格**，46 格对应格宽 45/46≈0.978°；
- 主文档行 1992 示例 `bins=np.arange(0,46.5,0.5)` 实际生成 **92 格**（边界 0,0.5,…,46.0）；
- 源码 `_phi_fit_chi2.py` 行 87 实际用 `bins=np.linspace(0,45,46)` → **45 格、1° 格宽**，与"每 0.5°"不符；
- **结论**：φ 定义、[0,45°] 值域、直方图分格流程在三种口径下逻辑一致；"46 格 vs 0.5° 一格"的精确格数是文档表述偏差，`verify.py` 对三种实现均给出数值，便于追溯。
