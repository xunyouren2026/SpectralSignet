# A02 prompt — 输入种子文本

> 组：A 模型与任务 | 状态：✅ 已用 | 数据源：主文档行 39-66、《参数完整定义与公式.txt》行 17-24、《参数审计与实验报告.txt》行 35

---

## ① 定义

`A02 prompt` 是送入模型的**输入种子文本**（UTF-8 字符串），触发模型推理的语义内容。默认实测值为主文档行 41 的宇宙膨胀句：

```
"The universe is expanding, and galaxies are drifting apart over time."
```

`A02` 决定了"指纹是在什么语义上下文中测量的"——但它本身**不产生指纹**，指纹由模型（A01）产生。A02 的核心作用是验证**跨输入指纹稳定性**：不同语义输入下指纹是否不变（主文档行 41）。

**默认/实测范围**：宇宙膨胀句 / NS 段落（规格行 23）。

---

## ② 公式

`A02` 是文本字符串，算法上经 tokenizer 转为整数 ID 序列：

```
A02: str → tokenizer → x ∈ Z^{1×T},  T ≈ 10-15 tokens（宇宙膨胀句）
```

它进入的指纹测量链路（主文档行 45-47）：

```
H = Embed(x) ∈ R^{T×d}        # 嵌入
逐层: H_l = Layer_l(H_{l-1})   # 24 层前向
β谱指纹（24 维）:  γ_l = Σ_{i≤M}s_i²/Σs_i²  (每层 SVD, M=3)
```

稳定性判据（主文档行 51-55）：

```
within  = E_{p≠p'} ||f_p - f_{p'}||   # 同模型跨 prompt 距离（实测 0.031）
cross   = ||f_Qwen - f_GPT2||         # 跨模型距离（实测 0.219）
分离比   = cross / within              # 实测 ≈ 7×
```

---

## ③ 物理/几何直觉与用途

**物理直觉**：把 prompt 看成"测量探针"。好的探针应当不改变被测系统的属性——若几何指纹随 prompt 漂移，它测量的就是"输入内容"，而非"模型身份"。A02 验证的就是"探针无关性"（measurement probe independence）。

**几何直觉**：同一模型的激活流形（manifold）是固定的几何对象，不同 prompt 只是在该流形上取了不同"采样路径"。若指纹稳定，说明指纹是流形的**内禀属性**（intrinsic），与采样路径无关；若漂移，说明指纹测到的是路径而非流形。

**用途**（主文档行 41-63）：
1. **输入无关性验证**——指纹稳定在模型家族级别，不随 prompt 漂移；
2. **来源判定前提**——"如果指纹随输入漂移，就无法用于身份识别"（主文档行 55）；
3. **输入异常探测**——低熵重复文本（"the the the…"）下指纹偏离可检测（主文档行 57）；
4. **稳定指纹基线**——多 prompt 指纹取平均/中位数，作为溯源参考锚点（主文档行 59）。

## ④ 推导过程

以宇宙膨胀句为例（主文档行 43-61）：

1. **token 化与嵌入**：句子切分为约 10-15 个 token，各映射为嵌入向量；指纹从第一层前向才开始测量（第 43 行）。
2. **逐层前向与激活捕获**：`A05=(k_proj,up_proj,o_proj)` 的投影输出被钩子捕获，形状 `(batch, seq_len, hidden_dim)`；这是指纹原始材料（第 45 行）。
3. **谱集中度计算**：逐层 PCA/SVD → β 谱指纹（24 维向量）描述每层信息在 C-子空间的集中程度（第 47 行）。
4. **换 prompt 重复**：切换语义不同的句子（广义相对论句、量子力学句），长度相近、主题不同（第 49 行）。
5. **指纹比对**：计算同实例跨 prompt 距离（within）。**实测 Qwen within = 0.031**，说明指纹对输入语义不敏感（第 51 行）。
6. **与跨模型距离对比**：同 prompt 下 Qwen 与 GPT-2 的指纹距离 **cross = 0.219**。分离比 `7×` 证明指纹区分的是"模型家族"而非"输入内容"（第 53 行）。
7. **输入无关性结论**：指纹是模型印记、不是输入印记（第 55 行）。
8. **极端输入测试**：低熵重复文本（"the the the…"）测试异常输入下指纹是否偏离（第 57 行）。
9. **多输入聚合**：所有 prompt 指纹平均/中位数 → 稳定指纹基线（第 59 行）。
10. **与 A01 协同**：换模型重测，同一 prompt 不同模型指纹不同 → 差异来自模型而非输入（第 61 行）。
