## ① 定义

`E07 ln_sigma` 定义 **lognormal 扰动强度**的对数标准差，固定为 **0.8**。

在 DEFF 尺度不变性测试中，对激活引入**乘性公共尺度扰动**：

$$H_{\text{pert}} = H \cdot e^{\epsilon},\qquad \epsilon \sim \mathcal{N}(0,\sigma^2),\quad \sigma = \ln\_sigma = 0.8$$

单次扰动可放大 `e^0.8 ≈ 2.23` 倍、缩小 `e^-0.8 ≈ 0.45` 倍；多次累积跨越约 11 倍范围（`2.23³ ≈ 11`，`0.45³ ≈ 0.09`）。

```python
ln_sigma = 0.8
scale_factors = np.exp(np.random.normal(0, ln_sigma, N_FRAMES))
```

**为什么是 0.8 而非 0.5 或 1.0？**
- **0.5（1.65 倍）**：扰动太小，不能充分测试尺度不变性；
- **0.8（2.23 倍）**：适中——单步约 2 倍、累计覆盖约 1 个数量级；
- **1.0（2.72 倍）**：过大，可能引入数值不稳定。

## ② 公式

lognormal 尺度因子：`s = e^ε`，`ε~N(0,σ²)`。其期望（lognormal 一阶矩）：

$$E[s] = e^{\sigma^2/2} = e^{0.32} \approx 1.377,\qquad
E[s^2] = e^{2\sigma^2} = e^{1.28} \approx 3.596$$

DEFF（比值型，尺度不变量）：

$$\text{DEFF}(c\kappa_1, c\kappa_2) = \frac{(c|\kappa_1|+c|\kappa_2|)^2}{(c\kappa_1)^2+(c\kappa_2)^2} = \frac{c^2(|\kappa_1|+|\kappa_2|)^2}{c^2(\kappa_1^2+\kappa_2^2)} = \text{DEFF}(\kappa_1,\kappa_2)$$

DEFF 漂移（E07 输出指标）：

$$\text{drift} = \frac{1}{N}\sum_{t=1}^{N}\Big|\text{DEFF}(\kappa^{(t)}_{\text{pert}}) - \text{DEFF}(\kappa^{(t)})\Big| \;\approx\; 0$$

energy_mean（尺度型，尺度敏感）：

$$E = \frac{1}{N}\sum_{i=1}^{N}\big(|\kappa_1^{(i)}| + |\kappa_2^{(i)}|\big) \;\xrightarrow{\;H \to cH\;}\; c \cdot E$$

比值-尺度解耦（本参数的核心验证目标）：

$$\text{corr}\big(\log R,\; \phi\big) \approx 0,\qquad
R = E[s]\,E_0 \;\text{(尺度量)},\qquad
\phi = \arctan\frac{|\kappa_2|}{|\kappa_1|} \;\text{(比质量)}$$

`φ` 只依赖曲率比 `|κ₂|/|κ₁|`，乘性公共扰动下不变；`logR` 随扰动漂移。两者统计独立 → 相关系数 ≈ 0。

## ③ 物理/几何直觉与用途

**物理直觉：ln_sigma 是"观察者坐标系的缩放幅度"。** 模型的激活幅度可以整体放大/缩小（等价于把坐标系标尺改变 11 倍），但**几何结构的内在形状不应改变**。DEFF 与 K% 是**尺度不变量**——它们反映几何结构的本质属性（有效维度、鞍面占比），而非坐标系刻度；energy_mean 与主曲率 κ 是**尺度敏感**量——它们随标尺漂移，是"观察者偏好"。

**用途：**
1. 验证 DEFF 的**强尺度不变性**：11 倍扰动下漂移 ≈ 0；
2. 用 `energy_mean` 作对照量：同一扰动下能量大幅漂移，反衬 DEFF 的不变性是**结构属性**而非数据本身没有尺度变化；
3. **比值-尺度解耦**：比值型几何量（DEFF、φ、λ、K%）与尺度型几何量（能量）统计独立（corr≈0），证明"自然结构"与"观测刻度"信息分离——这是指纹抗内容/尺度扰动的数学根源。

| 指标 | 对尺度扰动的响应 | 性质 |
|:---:|:---:|:---:|
| DEFF | 不变 | 尺度不变量（自然结构） |
| K% | 不变 | 几何比例（自然结构） |
| φ 主曲率角 | 不变 | 比值型（几何比例） |
| energy_mean | **大幅漂移**（~E[s]−1≈37.7%） | 尺度敏感（观察者偏好） |
| 主曲率 κ₁ | 大幅漂移 | 尺度敏感 |

## ④ 推导过程

**Step 1 — DEFF 的齐次性（尺度不变性的数学根基）。** DEFF 分子 `(|κ₁|+|κ₂|)²` 与分母 `κ₁²+κ₂²` 均为曲率的**二次齐次式**。对公共尺度 `c`，分子分母各得 `c²`，在比值中约去——不变量。这是判断"自然结构"（结构在尺度变换下稳定）的关键标准。

**Step 2 — energy_mean 的尺度响应。** `E = mean(|κ₁|+|κ₂|)` 是曲率的一阶齐次式，`E(cκ) = c·E`。在 lognormal 扰动下 `E_pert = s·E_0`，相对漂移的期望：

$$\frac{|E_{\text{pert}} - E_0|}{E_0} \;\xrightarrow{\text{期望}}\; E[s] - 1 = e^{\sigma^2/2} - 1 = e^{0.32} - 1 \approx 37.7\%$$

**Step 3 — 比值-尺度解耦（corr(logR,φ)≈0）。** 逐帧定义尺度量 `R_t = E_t`、比质量 `φ_t = median_i arctan(|κ₂,i|/|κ₁,i|)`。扰动下 `logR_t = log E_0 + log s_t`（`log s_t` 完全由 ln_sigma 驱动），而 `φ_t` 只随几何结构噪声波动，与 `s_t` 独立。独立随机变量的 Pearson 相关 → 0。这一解耦表明：**尺度自由度（可被攻击者操纵）与形状自由度（模型身份）在统计上分离**，指纹的比值型特征因此对尺度攻击免疫。

**Step 4 — 不同扰动强度的 DEFF 漂移（实测）：**

| ln_sigma | 尺度范围 | DEFF 漂移 | 判定 |
|:---:|:---:|:---:|:---:|
| 0.0 | 1×（无扰动） | 0.000 | 基准 |
| 0.3 | ~1.35× | 0.000 | 不变 |
| **0.8** | **~2.23×（单步）→11×（累计）** | **0.000** | **不变** |
| 1.0 | ~2.72× | 0.000 | 不变 |
| 1.5 | ~4.48× | 0.000 | 不变 |

DEFF 对 ln_sigma 完全不敏感——强尺度不变性成立。
