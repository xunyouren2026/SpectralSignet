## ① 定义

`D07 sp_grid` 定义 M4 模型（尖峰模型）中尖峰峰宽参数 sp 的搜索网格：**从 0.6° 到 6°，步长 0.2°**。M4 尖峰分量建模为集中在 φ≈0° 附近的高斯峰：

$$p_{\text{尖峰}}(\phi) = \frac{1}{Z}\exp\left(-\frac{\phi^2}{2\,sp^2}\right), \qquad 0 \le \phi \le 45°$$

- `a`：尖峰强度（D06 搜索），控制尖峰权重；
- `sp`：尖峰宽度（D07 搜索），控制尖峰锐度——`sp` 越小越窄越锐利。

**实测结果：M4 被否决。** 最优 a≈0.010，sp\*=2.4° 无统计学意义——尖峰分量本身不存在时，sp 的取值无关紧要。

**为什么是 0.6°-6°？** sp<0.6° 尖峰坍缩到单点（数值不稳、无物理意义）；sp>6° 尖峰与背景无法区分（参数不可识别）。实测最优 sp=2.4° 在范围内。

---

## ② 公式

```python
sp_values = np.arange(0.6, 6.01, 0.2)       # D07 sp_grid
a_values  = np.arange(0.0, 0.61, 0.01)      # D06 a_grid

pdf_spike = exp(-φ²/2·sp²) 截断[0,45] 归一化
pdf_mix   = (1-a)·截断高斯(μ,σ) + a·pdf_spike
chi2      = Σ (obs_fit - N·pdf_mix)² / (N·pdf_mix)
```

显著性（与 D06 共用 T05 判据）：`Δχ² = χ²(M3) - χ²(M4) > 5.99` 判尖峰显著（df=2, α=0.05）。

---

## ③ 物理/几何直觉与用途

**物理直觉**：sp 编码"异常集中方向"的锐度——极窄尖峰（sp≈1°）代表 φ≈0° 处过度集中（管状伪影）；宽尖峰（sp≈5-6°）接近背景、意义弱。

**几何直觉**：如果流形中存在大量"κ₂≈0 的伪影点"，φ≈0° 会形成尖锐峰。sp 越小，说明异常点越集中在同一个曲率比上——这在真实 LLM 激活流形中未被观察到。

**用途**：`D07` 的价值在于**与 D06 联合确认"不存在显著尖峰"**。实测所有模型（Qwen/GPT-2/NS/随机）M4 均被否决——最优 sp≈2.4° 只是噪声拟合的结果，不代表真实几何结构，这强化了 M3（平滑截断高斯）的普适性。
