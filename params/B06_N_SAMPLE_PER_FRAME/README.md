# B06 N_SAMPLE_PER_FRAME — 版本A每帧采样数

> 组别：B 几何计算 ｜ 实测状态：✅ 已用（N_SAMPLE=18）｜ 来源模块：ai_versionA
> 数据源：《参数附录表完整版》行 1261-1356；《参数完整定义与公式.txt》B06 项

## ① 定义

`B06 N_SAMPLE_PER_FRAME` 定义**版本 A 曲率计算**中每帧的采样点数，固定为 **18**。它与 `B05 SAMPLES_PER_FRAME` 数值相同，但属于两个不同计算模块的独立参数：

| 参数 | 所属模块 | 用途 |
|------|---------|------|
| B05 SAMPLES_PER_FRAME | 通用曲率采样 | 每帧采样点，用于所有曲率计算 |
| B06 N_SAMPLE_PER_FRAME | 版本 A 曲率采样 | 版本 A 特定实现的采样数 |

版本 A 采用 2D 主截面拟合方法，`N_SAMPLE_PER_FRAME` 是该方法的配置参数。两个参数数值相同（均为 18），但在不同模块中独立配置——若只改其一会导致版本 A 与通用曲率结果口径不一致。

## ② 公式

版本 A 曲率计算流程（与 B05 相同的有放回采样，但耦合到版本 A 核函数）：

1. **采样**：从帧内 8 个 token 激活有放回抽取 18 次 → `S∈R^{18×d}`；
2. **降维**：将 18 个采样点投影到 2D 主截面（局部主成分分析）；
3. **拟合**：在 2D 截面上拟合二次曲面 `z = a₁x²+a₂y²+a₃xy+b₁x+b₂y+c`；
4. **曲率**：从 Hessian 特征值计算主曲率 κ₁、κ₂。

同步约束（关键维护原则）：

$$N\_SAMPLE\_PER\_FRAME \;\equiv\; SAMPLES\_PER\_FRAME$$

## ③ 物理/几何直觉与用途

**物理直觉：B06 是版本 A 拟合算法的"专属采样器"。** 版本 A 的 2D 主截面拟合需要最少 6 个点确定 6 个二次曲面系数，18 个点提供 3 倍冗余平滑噪声。与 B05 的本质区别在**归属模块**：B06 直接耦合版本 A 核函数，若修改版本 A 拟合算法需同步调整该参数。

- 偏少（10 以下）→ 拟合不稳定，主曲率波动大；
- 适中（18）→ 稳定且高效；
- 偏多（30 以上）→ 计算成本增加，稳定性提升有限。

**用途**：控制版本 A 曲率拟合的稳定性；直接决定 DEFF_A（202）输出的可靠性。DEFF 平台 ≈1.58 的测量依赖该参数提供的稳定主曲率对 (κ₁,κ₂)。

## ④ 推导过程

**Step 1 — 主曲率与 DEFF。** 对拟合二次曲面求 Hessian `H = [[2a₁, a₃],[a₃, 2a₂]]`，特征值为主曲率 κ₁,κ₂。有效维数比：

$$DEFF = \frac{(|\kappa_1|+|\kappa_2|)^2}{\kappa_1^2+\kappa_2^2} \in [1,2]$$

- DEFF→2 对应极小曲面（|κ₁|=|κ₂|，两方向曲率同量级）；
- DEFF→1 对应圆柱（一个方向曲率为 0）。

**Step 2 — 平台值论证。** 对主曲率角 `φ = arctan(|κ₂|/|κ₁|)`，`DEFF = 1 + sin 2φ`。各向同性时 φ 均匀分布，`E[DEFF] = 1 + E[sin 2φ] = 1 + 2/π = π/2 ≈ 1.5708`（4R(2) 平台）。实测 1.5737-1.5920 与平台一致，偏差 <1.4%。

**Step 3 — 同步原则的必要性。** 版本 A 与通用曲率口径若不一致（如 B05 改 18、B06 忘改 30），DEFF_A 与 DEFF 将出现系统偏差，48 维联合特征中的曲率部分发生"模块内不一致"。维护原则：修改 B05 必须同步修改 B06。

## ⑤ 数值验证

- **实测值**：N_SAMPLE=18（已用）；DEFF 均值≈1.58、帧间 CV≈1.5%；10→CV 3.5%、18→1.5%、30→1.0%。
- 验证脚本 [verify.py](verify.py)：验证 B06==B05 同步原则，复现版本 A 全流程（采样→2D 投影→二次拟合→Hessian→κ₁,κ₂→DEFF），并验证 DEFF 平台 ≈π/2 与 DEFF∈[1,2]。
