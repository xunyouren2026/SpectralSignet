# A01 model — 被测模型路径 / HuggingFace ID

## ① 定义

`A01 model` 是被测模型的本地路径或 HuggingFace ID，是整个指纹提取流水线的**测量对象**。它本身只是一个字符串（路径/ID 标识符），**不产生任何输出**——它触发的是从"模型加载"到"家族溯源判定"的完整 10 阶段流水线（主文档行 11-35）。

```python
A01 model = "Qwen2.5-0.5B-Instruct"   # 默认实测值
```

关键性质（主文档行 13）：
- 它是**路径字符串**，不是模型本身；
- 模型家族（Qwen / GPT-2）是溯源分类的类别标签；
- 换 `A01`（如从 Qwen 换成 GPT-2）→ 同一 `A02 prompt` 下输出不同指纹 → 证明指纹差异来自**模型（A01）而非输入（A02）**。

**默认/实测范围**：`Qwen2.5-0.5B-Instruct`（三实例溯源 100%）。

---

## ② 公式

`A01` 本身不是数值量，而是"标识符 → 参数"的映射：

```
A01 := (path, id) | path ∈ 本地路径, id ∈ HuggingFace ID
```

它驱动的关键公式（主文档行 15-29）：
- 模型加载：`AutoModelForCausalLM.from_pretrained(A01, dtype=float32, local_files_only=True)`
- 谱集中度（触发后由 B01/M 计算）：

  $$\gamma = \frac{\lambda_1+\lambda_2+\lambda_3}{\sum_{i=1}^{d}\lambda_i} = \frac{\sum_{i\leq M}s_i^2}{\sum_i s_i^2},\quad M=3$$

- 家族溯源判定（与 A06 配合）：

  $$\text{判定} = \arg\min_{c\in\{\text{Qwen系},\text{GPT-2系}\}} \|f_{A01} - f_c^{(ref)}\|$$

  其中 `f` 为 48 维联合指纹（β 谱 24 维 + 曲率 24 维，主文档行 29）。

## ③ 物理/几何直觉与用途

**物理直觉**：把模型看作一台"几何引擎"——每一层的激活是流形上的点集。`A01` 决定了"哪台引擎"被测量；不同家族的引擎在流形几何上留下不同的"印记"（谱集中度 γ、曲率 K%/DEFF 不同）。指纹是**模型的印记，不是输入的印记**（主文档行 61-63）。

**几何直觉**：C-子空间（Gegenbauer l≤2，M=3）是最低阶几何模态。γ 高 → 激活能量集中在低维子空间 → 流形"低秩/可压缩"；γ 低 → 能量弥散 → 流形"高维展开"。Qwen 系与 GPT-2 在此度量下有家族级差异。

**用途**：
1. **溯源分类标签**——Qwen/GPT2 是类别标签，A01 指定被测对象；
2. **驱动 10 阶段流水线**（主文档行 13-33）：加载(step1) → 钩子(step2) → 输入生成(step3) → 实时捕获(step4) → 分帧聚合(step5) → 曲率(step6) → 谱集中(step7) → 指纹组装(step8) → 工程指标(step9) → 阈值裁决(step10)；
3. **SFT 不变性验证**（`_aiq_verdict.py`）：base vs Instruct 指纹 corr≈1 → 指纹是"身份度量"，不是"智能度量"。

## ④ 推导过程

以 `A01 = "Qwen2.5-0.5B-Instruct"` 为例，10 阶段流水线（主文档行 13-33）：

1. **模型加载**：`from_pretrained(dtype=float32)` 载入内存，`H01 seed=0` 固定随机状态。
2. **注册钩子**：`A04=None` 自动全选，`A05=(k_proj,up_proj,o_proj)` 过滤投影类型，`G03 max_dim=8192` 跳过超大输出层（lm_head）。
3. **输入生成**：`A02 prompt` → tokenizer → 输入 ID；`A03 gen_len=64` 控制逐 token 生成。
4. **实时捕获**：对每 token，`B10 anchor` 中间层 k_proj 输出经 `B01 M=3` C-子空间投影，得 β_t ∈ [0,1]。
5. **分帧聚合**：`B04 TOK_PER_FRAME=8`，每 8 token 一帧；`B05 SAMPLES_PER_FRAME=18` 采样；`B07 K_NN_CURV=15` 近邻。
6. **曲率计算**：每帧独立算 K%、DEFF_A、Hmed（版本 A 曲率三件套）。
7. **谱集中计算**：`C01 energy_thr=0.90` 扫描 k90；`C02 ks=[1,2,4,8,16]` 绘制压缩比曲线。
8. **指纹组装**：β 谱 24 维 + 曲率 24 维 = 48 维联合特征 → 与 A06 三实例参考库比对。
9. **工程指标**：`F01 ctx=4096`（OOM 降档 1024）、`F02 bandwidths` 三档带宽 → tok/s 估算。
10. **阈值裁决**：`T01 |DEFF-1.56|≤0.15`、`T03 K%∈[20,57]%`、`T02 CV≤3%`。

**输出命题**（可由 `_aiq_verdict.py` 数值复现）：当 A01 指向 Qwen 系时，指纹与 Qwen 参考簇距离 < 与 GPT-2 参考簇距离（主文档行 29）。

## ⑥ 与关联参数的关系

| 关联参数 | 关系 |
|----------|------|
| A02 prompt | A01 控制指纹**来源**（模型），A02 控制指纹**测量上下文**（输入）；两者组合验证"指纹=模型属性≠输入伪影" |
| A03 gen_len | 生成 token 数，决定 A01 测量采样的统计量规模（帧数 = gen_len/8） |
| A04 layer_names | 与 A01 的层结构绑定：Qwen 24 层、GPT-2 12 层 |
| A05 projs | 决定测 A01 的哪些投影；Qwen 系 o>k>q>gate>down>v>up |
| A06 三实例路径 | 提供溯源参考库，A01 的判定基准（base/instruct/gpt2） |
| B01 M、B10 anchor | A01 激活经 M=3 C-子空间投影得 β_t |
| B04-B08 | 分帧/采样/曲率参数，决定 A01 指纹的统计稳定性 |
| H01 seed、H05 dtype | 运行环境：seed=0 可复现、float32 加载精度 |
| G03 max_dim | 跳过 A01 的超大输出层（lm_head，>8192）防 OOM |
| T01/T02/T03 | 对 A01 指纹做稳态/平台/槽位裁决 |
