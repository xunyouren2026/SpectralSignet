## ① 定义

`D04 μ_grid` 定义 M3 模型（截断高斯分布）最优均值 μ 的搜索网格：**从 5° 到 40°，步长 0.5°**。M3 假设 φ 分布在 `[0, 45°]` 上服从截断高斯：

$$p(\phi) \propto \exp\left(-\frac{(\phi - \mu)^2}{2\sigma^2}\right), \qquad 0 \le \phi \le 45°$$

μ 是高斯峰值位置（分布中心），σ 由 `D05 σ_grid` 同步搜索。`μ_grid` 在 5°-40° 内网格搜索，取使 χ² 最小的 μ。

**实测最优值：μ≈14°**。在 14° 处 χ² 最小、p=0.91——这是 M3 在 Qwen 0.5B 上胜出的关键证据。

**为什么是 5°-40°？** μ<5° 意味着分布坍缩到 0°（近一维管状，真实数据极少且拟合不稳）；μ>40° 意味着坍缩到 45°（椭球面主导，罕见）。0.5° 步长足以定位 μ 的真实值（±0.5° 不影响结论）。

## ② 公式

截断高斯期望频数（源码 `exp_gauss`）：

$$\text{PDF}(\phi) = \frac{1}{\sqrt{2\pi}\,\sigma}\frac{e^{-(\phi-\mu)^2/2\sigma^2}}{\Phi(45°|\mu,\sigma) - \Phi(0°|\mu,\sigma)}$$

$$E_i = N \cdot \left[\Phi(\phi_i^{hi}|\mu,\sigma) - \Phi(\phi_i^{lo}|\mu,\sigma)\right] \big/ \left[\Phi(45°|\mu,\sigma) - \Phi(0°|\mu,\sigma)\right]$$

联合网格搜索：

```python
mus    = np.arange(5.0, 40.01, 0.5)     # D04
sigmas = np.arange(2.0, 30.01, 0.5)     # D05
for mu in mus:
    for sigma in sigmas:
        chi2 = np.sum((obs_fit - exp_gauss(mu, sigma))**2 / exp_gauss(mu, sigma))
```

## ③ 物理/几何直觉与用途

**物理直觉**：μ 是 φ 分布峰值所在角度，直接回答"流形上主曲率比最常取什么值"。各向同性流形 → 峰值在 22.5°；鞍面主导 → 峰值偏向低角度。

**几何直觉**：实测 μ≈14° 意味着

$$\frac{|κ₂|}{|κ₁|} \approx \tan(14°) \approx 0.25$$

即第二主曲率幅度约是第一主曲率的 25%——κ₁、κ₂ 幅度不等、符号相反，鞍面点占比高。这是"鞍面主导型"流形的定量特征，显著偏离各向同性（22.5°）。

**用途**：μ 是 M3 模型的核心参数，决定 φ 分布形态判据（302 输出指标），并用于跨域对比：Qwen（14.1°）vs GPT-2（15.2°）vs NS 湍流（14.5°）vs 随机数据（22.5°），支持"跨域几何同构"结论。
