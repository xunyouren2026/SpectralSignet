## ① 定义

`A06 三实例路径` 是三个模型的本地路径，用于建立指纹溯源的**"参考三角"**（主文档行 443-457）：

| 实例 | 路径 | 说明 |
|------|------|------|
| qwen_b | `C:\...\_models\Qwen2.5-0.5B` | Qwen 基础版（base） |
| qwen_i | `C:\...\_models\Qwen2.5-0.5B-Instruct` | Qwen 指令微调版（Instruct） |
| gpt2 | `E:\gpt2-124m` | GPT-2 124M（外族对照） |

**三实例构成参照系**（主文档行 455-457）：
- `qwen_b` 与 `qwen_i`：同架构、同规模，**仅 SFT 微调不同**；
- `gpt2`：不同架构、不同规模、不同训练数据，**属于不同模型家族**。

> 为什么选这三个？验证两个独立问题：① 同一家族内 SFT 微调是否改变指纹（base→Instruct 漂移）；② 不同家族指纹是否有足够区分度（Qwen 系→GPT-2 分离度）。（主文档行 458）

**默认/实测范围**：base/instruct/gpt2，已用。

## ② 公式

```
A06 := {qwen_b: path, qwen_i: path, gpt2: path}   # 3×路径
```

核心度量（主文档行 462-470 / 规格行 636）：
- 指纹间距离：`d(a,b) = ||f_a - f_b||`（欧氏；β 谱 24 维 + 曲率 24 维 = 48 维联合特征）
- 家族溯源判定：

$$c^{*} = \arg\min_{c\in\{\text{Qwen系},\text{GPT-2系}\}} d(f_{\text{unknown}}, f_c)$$

- 归一化边距：$\text{margin} = \frac{1}{N}\sum_i \frac{d(\cdot,\text{GPT2}) - d(\cdot,\text{Qwen})}{\text{scale}}$
- 分离比：$\text{ratio} = \frac{\text{cross}}{\text{within}} = \frac{d(\text{Qwen},\text{GPT2})}{d_{\text{同实例跨prompt}}}$

**实测距离矩阵**（主文档行 524-528）：

|      | qwen_b | qwen_i | gpt2 |
|------|--------|--------|------|
| qwen_b | 0 | **0.009** | **0.219** |
| qwen_i | 0.009 | 0 | **0.215** |
| gpt2 | 0.219 | 0.215 | 0 |

## ③ 物理/几何直觉与用途

**物理直觉**：三实例 = 一族"已知标记"的参考样本。指纹溯源 = 最近邻分类——未知模型的指纹落在哪个参考簇附近，就判为哪个家族。同架构 SFT（base→Instruct）只改变权重表面的"功能层"，不改变深层几何结构 → 指纹距离 ≈ 0（0.009）；不同架构家族的几何结构不同 → 距离大（0.219）。

**几何直觉**：base 与 Instruct 在指纹空间中"重叠"（距离 0.009 < 实例内厚度 0.030 → 不可区分），说明指纹是**家族级**而非**实例级**属性；GPT-2 与 Qwen 的距离 7 倍于实例内厚度 → 跨家族可区分。指纹抗 SFT 微调 → 溯源不可伪造（主文档行 566-568）。

**用途**（主文档行 462-469）：
1. 验证 SFT 微调是否保留指纹（base vs instruct 距离 ≈ 自身波动 → SFT 不改变指纹）；
2. 验证跨家族区分度（分离比 > 2 → 指纹可溯源家族）；
3. 新样本家族归类（最近参考簇 → 溯源准确率）；
4. 重生成边距验证（margin > 0.2 → 重生成溯源安全门槛）。

## ④ 推导过程

完整操作流程（主文档行 474-597）：

1. **准备三个模型**（行 476-489）：确保下载到本地；缺 base 用 `hf-mirror.com` 下载。
2. **配置 A06**（行 493-500）：三个路径存入字典。
3. **加载参考模型并计算指纹**（行 505-512）：同一 `A02 prompt` 下生成，各算 β 谱指纹（24 维）。
4. **距离矩阵**（行 522-528）：0.009 / 0.219 / 0.215。解读：qwen_b-qwen_i 距离 0.009 ≈ 同实例跨 prompt 波动 0.030 → **不可区分**；Qwen 系与 GPT-2 距离 0.219 ≈ 7 倍于实例内厚度 → **跨家族可区分**。
5. **新样本溯源**（行 535-547）：`dist_to_qwen < dist_to_gpt2` → 判 Qwen 家族。
6. **准确率与边距**（行 549-559）：21 样本（无扰动 7 + 改写 12 + 截断 6 + 重生成 3），溯源 **100%**；重生成边距 **0.2975**（+54% vs 基线）。
7. **判断标准**（行 561-568）：acc=100% 有效；margin>0.2 安全；分离比>2 抗 SFT；corr≈1（base vs instruct）不可伪造。
8. **报告**（行 579-597）：β 谱 24 + 曲率 24 = 48 维；acc 100% (21/21)；base vs instruct 距离 0.009；Qwen vs GPT-2 距离 0.219（分离比 7×）；margin 0.2975。

**源码对照**（`_aiq_verdict.py`）：加载 base/instruct 两实例 → 逐层 spl_gamma 剖面 → corr=0.9999（SFT 不变性）。
