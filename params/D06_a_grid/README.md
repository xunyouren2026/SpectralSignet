## ① 定义

`D06 a_grid` 定义 M4 模型（尖峰模型）中尖峰强度参数 a 的搜索网格：**从 0 到 0.6，步长 0.01**。M4 假设 φ 分布由平滑背景 + 尖峰分量混合：

$$p(\phi) = (1-a)\cdot p_{\text{背景}}(\phi) + a\cdot p_{\text{尖峰}}(\phi)$$

- `p_背景`：平滑背景分布（取 M3 截断高斯，实测 μ=14°, σ=25°）；
- `p_尖峰`：集中在 φ≈0° 附近的高斯尖峰（`p_spike ∝ exp(-φ²/2sp²)`，宽度由 D07 控制）；
- `a`：尖峰权重（0-1）。

`a_grid` 搜索使 χ² 最小的 a。**若最优 a 显著 >0（Δχ²>5.99）→ 存在异常尖峰；若 a≈0 → 无需尖峰分量。**

**实测结果：M4 被否决。** 最优 a≈0.010，Δχ²=2.3<5.99——φ 分布无异常尖峰，M3 足以描述数据。

---

## ② 公式

尖峰模型期望频数：

```python
a_values = np.arange(0, 0.61, 0.01)          # D06 a_grid
sp_values = np.arange(0.6, 6.01, 0.2)        # D07 sp_grid

pdf_bg    = 截断高斯(μ_best, σ_best)          # 实测 μ=14, σ=25
pdf_spike = exp(-φ²/2·sp²) 截断[0,45] 归一化  # 0° 尖峰
pdf_mix   = (1-a)·pdf_bg + a·pdf_spike
chi2      = Σ (obs_fit - N·pdf_mix·0.5)² / (N·pdf_mix·0.5)
```

显著性判据（T05）：

$$\Delta\chi^2 = \chi^2_{\text{M3}} - \chi^2_{\text{M4}},\qquad \Delta\chi^2 > 5.99 \;\Rightarrow\; \text{尖峰显著}\ (df=2,\ \alpha=0.05)$$

## ③ 物理/几何直觉与用途

**物理直觉**：a 回答"φ 分布在某个特定角度是否过度集中"。尖峰的可能来源：数值伪影（曲率估计不稳）、真实几何结构（特定曲率比占主导）、统计波动。

**几何直觉**：φ≈0° 尖峰 = 管状主导（κ₂≈0 的点异常多）；φ≈45° 尖峰 = 各向同性鞍面主导。若流形是纯鞍面主导的平滑形态，a 最优值应≈0。

**用途**：`D06` + `D07` + `T05` 构成"异常尖峰检测"系统。实测所有模型（Qwen/GPT-2/NS 湍流/随机数据）M4 均被否决——"φ 分布无异常尖峰"是跨模型、跨域的普遍特征，也是 M3（截断高斯）成立的前提。

## ④ 推导过程

**第一步（行 2577-2582）：构建 D01 直方图。**

**第二步（行 2584-2608）：对每个 (a,sp) 计算 M4 期望频数。** 背景取 M3 最优 (μ,σ)（`pdf_bg` 归一化），尖峰取 `exp(-φ²/2sp²)`（D07），混合后乘总样本数；χ² 在拟合域计算。

**第三步（行 2611-2625）：取 χ² 最小的 (a,sp)。** 实测最优 a=0.010, sp=2.4°, χ²=39.8。

**第四步（行 2627-2647）：Δχ² 显著性。** `χ²(M3)=42.1`，`χ²(M4)=39.8`，`Δχ²=2.3 < 5.99` → **尖峰不显著，M4 被否决**。

**第五步（行 2649-2658）：a 扫描表。** a=0 →42.1（M3 基线）；a=0.010 →39.8（Δ=2.3）；a=0.030 →40.5（Δ=1.6）；a=0.050 →41.8（Δ=0.3）。最优 a=0.010 但 Δχ²<5.99。

**第六步（行 2660-2672）：产出。** 结论：M4 被否决，M3（截断高斯）胜出。
