## ① 定义

`T04 AIQ因子权重` 是 AIQ（**A**I **Q**eometry Quotient，几何智能商，0–100）计算中五个因子的**权重分配方案**。AIQ 综合五个几何健康因子，作为「流形几何质量」的单一标量度量。

权重分配：

| 因子 | 权重 | 排名 | 含义 |
|------|:----:|:----:|------|
| f₁（β均值/芯坍缩） | **0.20** | 并列第 2 | 谱集中度的整体水平（mean γ） |
| f₂（DEFF稳定度） | **0.25** | **第 1** | 流形维度锁定的稳定性 |
| f₃（H→0收敛度） | **0.20** | 并列第 2 | 趋近极小曲面的程度 |
| f₄（SPL集中度） | **0.20** | 并列第 2 | 锚定层的谱集中度 |
| f₅（低模纯度） | **0.15** | 第 3 | 跨层谱纯度的稳定性 |
| **总计** | **1.00** | — | 归一化 |

实测状态：**设计**（权重为设计值；各因子实测值见审计报告 407 项，AIQ=58.20）

## ② 公式

$$\text{AIQ} = 100 \times \big(0.20\,f_1 + 0.25\,f_2 + 0.20\,f_3 + 0.20\,f_4 + 0.15\,f_5\big)$$

归一化约束：

$$0.20 + 0.25 + 0.20 + 0.20 + 0.15 = 1.00 \;\checkmark$$

五因子定义（源码口径，[`_local_whitebox_detect.py`](file:///c:/Users/小冰/Desktop/宇宙/AIQ/_local_whitebox_detect.py) 行 304-308）：

$$f_1 = \overline{\gamma} = \text{mean}(\gamma_{\text{层}}), \qquad f_2 = 1 - \frac{\text{std}(DEFF)}{\text{mean}(DEFF)}$$

$$f_3 = 1 - \min\!\big(1,\; \overline{|H|}\big), \qquad f_4 = \overline{\gamma}_{SPL}, \qquad f_5 = 1 - \big(\max\gamma - \min\gamma\big)$$

各因子截断到 `[0,1]`。

## ③ 物理/几何直觉与用途

- **f₂ 权重最高（25%）的原因**：f₂ = 1 − CV(DEFF) 是**跨域几何同构的最强证据**——NS 的 CV≈0.25%，AI 的 CV≈1.07%，两者同 <2%。DEFF 平台锁定是「耗散最大化吸引子」的核心表征，几何稳定性直接对应「流形已锁定」的置信度，因此给最高权重。
- **设计哲学**：
  - 强调**几何锁定**（f₂ 最高）
  - 平衡**谱集中**（f₁ + f₄ = 0.40，各 0.20）
  - **预留收敛空间**（f₃ 权重 0.20：短链时 |H| 未趋 0 → f₃≈0 拖累 AIQ；长链时提供提升空间）
  - **低模纯度调节**（f₅ = 0.15，辅助调整）
- **用途**：将多维几何证据压缩为单个 0-100 标量，用于纵向监控推理健康的趋势；也是家族级溯源之外的「几何智能」辅助度量。

## ④ 推导过程

**Step 1 — 因子归一化。** 每个因子定义在 `[0,1]`：
- f₁/f₄ 是能量占比（0-1 天然归一）；
- f₂ 是 CV 的互补量（CV∈[0,1] 量级）；
- f₃ 用 `min(1, mean|H|)` 归一（|H| 中位数为 1.3152 时 f₃≈0）；
- f₅ 是跨层 γ 极差（span）的互补量。

**Step 2 — 权重归一化。** 五权重之和为 1，保证 AIQ ∈ [0,100]。

**Step 3 — 实测因子代入（审计报告 407 项 / `_param_audit_report.py` 行 54）。**

```
f1芯坍缩=0.625  f2DEFF稳定度=0.989  f3H→0收敛=0.000
f4SPL集中=0.625  f5低模纯度=0.565
```

$$\text{AIQ} = 100 \times (0.2\!\times\!0.625 + 0.25\!\times\!0.989 + 0.2\!\times\!0.000 + 0.2\!\times\!0.625 + 0.15\!\times\!0.565)$$
$$= 100 \times (0.1250 + 0.24725 + 0.0000 + 0.1250 + 0.08475) = 100 \times 0.58200 = \mathbf{58.20}$$

**Step 4 — 为什么 f₃=0.000 最低。** 短链下 `mean|H| ≈ 1.3152`，`min(1, 1.3152)=1` → f₃ = 1−1 = 0。|H| 尚未趋 0（NS 饱和态 |H|med≈0.003），即流形**尚未收敛到极小曲面**。这符合短链状态，同时意味着长链解封后 AIQ 有提升空间（预测 63-76）。
