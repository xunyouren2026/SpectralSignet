## ① 定义

`E01 REF_PROMPTS` 定义用于建立 **基线指纹（baseline fingerprint）** 的参考 prompt 数量，固定为 **4 句**。

在家族溯源中，指纹必须在不同输入下保持稳定——同一个模型处理不同 prompt 时应产出高度相似的指纹。`REF_PROMPTS` 提供一组语义相异的参考 prompt，系统对每个参考 prompt 分别提取指纹，再取**均值**作为该模型的"基线指纹"，后续所有扰动样本（改写/截断/重生成）都与该基线比对。

```python
REF_PROMPTS = [
    "The universe is expanding, and galaxies are drifting apart over time.",   # 宇宙
    "General relativity describes gravity as the curvature of spacetime.",     # 相对论
    "Quantum mechanics governs the behavior of particles at the smallest scales.",  # 量子
    "Thermodynamics studies heat, work, and the flow of energy."               # 热力学
]
```

（源码 `_qwen_robustness.py` 中为 4 个不同句子，覆盖地质/神经网络/热力学/宇宙学语义域。）

**为什么是 4 句而非 1 或 10？**
- **1 句不够**：指纹可能恰与该 prompt 的语义相关，无法证明输入无关性；
- **10 句更好但耗时**：每句需完整前向 + 指纹提取，计算量线性增长；
- **4 句是经验平衡值**：覆盖 4 个不同语义域，又能证明跨 prompt 稳定性。

## ② 公式

设参考 prompt 集合为 `{p₁, p₂, p₃, p₄}`，对每个 prompt 提取指纹向量 `fᵢ ∈ ℝ^d`（源码为 48 维：β 谱 24 维 + 版本 A 曲率 24 维）。基线指纹为逐维均值：

$$\text{baseline} \;=\; \bar{f} \;=\; \frac{1}{4}\sum_{i=1}^{4} f_i$$

基线标准差（跨 prompt 波动带）：

$$\text{baseline\_std} \;=\; \sqrt{\frac{1}{4}\sum_{i=1}^{4}\big\|f_i - \bar{f}\big\|_2^2}$$

跨 prompt 距离（同实例内两两欧氏距离均值）：

$$\text{within\_dist} \;=\; \frac{1}{\binom{4}{2}}\sum_{i<j} \big\|f_i - f_j\big\|_2$$

分离比（跨模型距离 / 跨 prompt 距离，衡量"输入无关性"的强度）：

$$\text{separation} \;=\; \frac{\text{cross\_model\_dist}}{\text{within\_dist}}$$

## ③ 物理/几何直觉与用途

**物理直觉：4 个参考 prompt 是对"模型身份流形"的多次独立测量。** 指纹不是模型的"坐标"而是模型在激活几何中留下的**结构签名**（β 谱能量集中剖面 + 曲率特征）。同一模型的多次测量应落在身份流形的同一邻域内（band 极窄）；不同模型则落向不同区域。`REF_PROMPTS` 的数量决定了"测量精度"：

- **M=1（单次测量）**：无法区分"模型身份"与"输入语义"，指纹混入 prompt 内容噪声；
- **M=4（四次测量取均值）**：随机语义噪声被 $\propto 1/\sqrt{4}$ 平均掉，剩下的才是稳定的模型身份；
- **M=16**：测量噪声已降至 $1/\sqrt{16}$，但收益递减（0.031→0.030）。

**用途：**
1. 建立家族溯源所需的**基线指纹**（`ref[w] = ps.mean(0)`）；
2. 量化**输入无关性**——同实例跨 prompt 距离 `0.031` 远小于跨模型距离 `0.219`，分离比 `7×`；
3. 为 E02/E03/E04 的扰动样本提供比对基准（MAD 的定义以基线为参照）。

## ④ 推导过程

**Step 1 — 基线指纹作为最小方差估计。** 设第 i 次测量 `fᵢ = f* + ξᵢ`，其中 `f*` 为模型真实身份指纹，`ξᵢ` 为输入语义引入的零均值噪声（`E[ξᵢ]=0`，协方差 `Σ`）。N 次测量的均值：

$$\bar{f}_N = f^* + \frac{1}{N}\sum_{i=1}^{N}\xi_i,\qquad
\text{Var}(\bar{f}_N) = \frac{1}{N}\,\text{tr}(\Sigma)$$

均值方差随 N 线性下降——这是 `4 句` 相对 `1 句` 的核心增益：噪声被平均掉，基线向真实身份靠拢。

**Step 2 — 4 句平台的饱和论证。** 实测稳定性随参考句数：

| 参考 prompt 数 | 跨 prompt 距离 | 基线稳定性 | 计算时间 |
|:---:|:---:|:---:|:---:|
| 1 句 | — | 低（依赖特定 prompt） | 1× |
| **4 句** | **0.031** | **高** | **4×** |
| 8 句 | 0.030 | 高 | 8× |
| 16 句 | 0.030 | 高 | 16× |

4 句已达稳定平台：增加句数距离几乎不变（0.031→0.030），噪声方差已小到被指纹固有结构差异主导，再增加只线性增加计算成本。

**Step 3 — 分离比 7× 的含义。** 跨模型距离 `0.219` 来自 Qwen 家族与 GPT-2 家族指纹的结构差异；跨 prompt 距离 `0.031` 来自同模型内部的语义噪声。`7×` 意味着"模型身份信号"强于"输入语义噪声"一个数量级——这是指纹可作身份标识的**量化判据**。

## ⑤ 数值验证

- **实测值**：同实例跨 prompt 距离 `0.031`；跨模型距离 `0.219`；分离比 `7×`；4 个 prompt 的指纹曲线几乎重合（band 极窄）。
- 实测环境：MVI-2 跨架构 sanity 实验（Qwen2.5-0.5B-Instruct vs GPT-2）。
- 验证脚本 [verify.py](verify.py)：合成 24 维 β 剖面，构造 4 个参考 prompt 剖面（加可控噪声使两两欧氏距离 ≈ 0.031）、另一模型参考剖面（与 Qwen 基线距离 ≈ 0.219），复现基线指纹、跨 prompt 距离、分离比 7×，并对比 1/4/8/16 句的稳定性平台。**合成数据仅验证算法逻辑，数值对齐实测量级。**
