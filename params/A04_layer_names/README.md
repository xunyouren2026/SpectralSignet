## ① 定义

`A04 layer_names` 指定哪些层参与指纹提取。默认 `None` 表示**自动全选所有线性层**（k_proj、up_proj、o_proj 等）；也可以手动指定层子集（主文档行 175）。

```python
layer_names = None   # 自动全选（默认）
layer_names = ["model.layers.0.self_attn.k_proj", ...]  # 手动子集
```

**层结构（主文档行 199）**：Qwen 24 层（0-23），GPT-2 12 层（0-11）。默认全选时指纹由 `24 层 × 3 投影 = 72 个点` 组成（主文档行 210）。

**默认/实测范围**：`None`（全选），已用。

## ② 公式

```
A04 := list[str] | None
None → 全选: L = {model.layers.i.<proj> : i∈[0,N), proj∈A05}
指定 → 过滤: L' = {l ∈ L : l 匹配指定前缀/名称}
```

指纹构成：`指纹 = {β_l, K%_l, DEFF_l, ... : l ∈ L'}`。层子集指纹（主文档行 245-249）：

| 层区 | 层号 | β 均值 | DEFF | K% | 功能标签 |
|------|------|--------|------|-----|----------|
| 浅层 | 0-7 | 0.2-0.3 | ~1.4 | ~30% | 输入编码重塑区 |
| 中层 | 8-15 | 0.5-0.8 | ~1.58 | ~45% | 高保真传输区 |
| 深层 | 16-23 | 0.3-0.6 | ~1.55 | ~50% | 输出前重组区 |

消融贡献（主文档行 279-291）：剔除层 l 后指纹变化

$$\Delta_l = \|f_{\text{full}} - f_{\text{full}\setminus\{l\}}\|$$

\Delta_l 最大者 = 核心指纹层。

## ③ 物理/几何直觉与用途

**物理直觉**：信息流经模型时经历"编码 → 传输 → 重组"三阶段。不同深度的激活流形几何不同：
- **浅层（0-7）**：输入编码重塑区，信息尚未集中到 C-子空间 → β 低（0.2-0.3）；
- **中层（8-15）**：高保真传输区，信息集中度最高 → β 峰值（0.5-0.8）；这也是 `B10 anchor` 选中间层（layer12.k_proj）做 β_t 实时追踪的原因（主文档行 230）；
- **深层（16-23）**：输出前重组区，信息重新弥散 → β 回落（0.3-0.6）。

**几何直觉**：中层流形"最接近低秩/集中态"，是家族指纹的**核心贡献区**；浅层跨模型差异小（贡献中），深层波动大（贡献中）。

**用途**：
1. **分层指纹对比**——定位"指纹核心贡献区"（中层）与"功能分区边界"（三层结构，主文档行 251）；
2. **轻量化**——只挂关键层子集，减少计算开销；
3. **消融定位**——逐步剔除层，找出对指纹区分度贡献最大的层（主文档行 279-291）；
4. **实时监控**——将监控锚定到中层（最稳定、区分度最高，主文档行 315）。

## ④ 推导过程

完整操作流程（主文档行 177-313）：

1. **查看层结构**（行 179-197）：`model.named_modules()` 过滤 `"k_proj"` → 输出 `model.layers.0..23.self_attn.k_proj`。
2. **默认全选（None）**（行 201-210）：自动全选 → 24×3=72 点指纹。
3. **浅层子集（0-7）**（行 212-220）：β 值较低（约 0.1-0.3）——输入编码重塑区。
4. **中层子集（8-15）**（行 222-230）：β 最高（约 0.5-0.8）——高保真传输区，B10 anchor 的依据。
5. **深层子集（16-23）**（行 232-240）：β 回落（约 0.3-0.6）——输出前重组区。
6. **分层对比**（行 242-251）：三层结构表（见 ②），对应"三层几何结构"。
7. **层×投影组合**（行 253-275）：`model.layers.{i}.self_attn.k_proj` 或 `.mlp.up_proj`；k_proj 集中（β≈0.7）、up_proj 弥散（β≈0.3）。
8. **消融实验**（行 277-291）：全选指纹 vs 逐层剔除 → 差分最大层为核心指纹层。
9. **判断标准**（行 293-299）：中层贡献最大（家族指纹核心）、浅层贡献中、深层贡献中。
10. **报告**（行 301-313）：浅 β=0.25/DEFF=1.42/K%=32%；中 β=0.62/1.58/46%；深 β=0.45/1.55/51%。

## ⑥ 与关联参数的关系

| 关联参数 | 关系 |

| A01 model | 层数由模型决定：Qwen 24 层、GPT-2 12 层 |

| B08 NFRAME | 分层指纹的曲率特征帧数 |
| A06 三实例路径 | 分层指纹作为溯源参考的一部分 |
