# B05 SAMPLES_PER_FRAME — 每帧曲率采样点数

> 组别：B 几何计算 ｜ 实测状态：✅ 已用（SAMPLE=18）｜ 来源模块：whitebox
> 数据源：《参数附录表完整版》行 1117-1260；《参数完整定义与公式.txt》B05 项

## ① 定义

`B05 SAMPLES_PER_FRAME` 定义每帧内随机采样的点数，固定为 **18**。每帧含 `B04 TOK_PER_FRAME=8` 个 token 激活（每个 d 维），曲率估计需要从这些激活中采样若干点拟合 2D 主截面。**采样是有放回的**（8 个 token 不足 18 个不同点），平均每个 token 被采样约 18/8=2.25 次。

## ② 公式

有放回采样：

$$(i_1,\dots,i_{18}) \sim \text{Uniform}(\{1,\dots,8\})^{18}\ \text{i.i.d.},\qquad S = H_{frame}[i_1:\dots:i_{18}] \in \mathbb{R}^{18\times d}$$

经验关系（与 B04 协同）：

$$B05 \;\approx\; 2\times B04 + 2,\qquad B04=8 \Rightarrow B05\approx 18$$

## ③ 物理/几何直觉与用途

**物理直觉：B05 是"曲率拟合的统计冗余旋钮"。** 版本 A 曲率通过 2D 主截面拟合实现：在激活流形上取一个 2D 截面，拟合二次曲面，从 Hessian 特征值算主曲率。二次曲面有 6 个系数（3 二次项 + 2 线性项 + 1 常数项），**最少需 6 个点**确定；18 个点提供 3 倍冗余抵抗噪声。有放回采样在 token 数不足时平滑异常值——即使某个 token 激活异常，其影响也会被重复采样平均掉。

- 采样偏少（8-12）→ 统计波动大，曲率估计不稳；
- 适中（18）→ 计算与稳定性平衡；
- 偏多（32-50）→ 重复点增多，边际收益递减。

**用途**：直接控制曲率估计的统计可靠性；每个采样点贡献一个主截面特征值对，最终 DEFF 是所有采样点的聚合（配合 202 DEFF_A）。

## ④ 推导过程

**Step 1 — 拟合最小点数。** 二次曲面 `z = a₁x²+a₂y²+a₃xy+b₁x+b₂y+c` 含 6 个未知系数。最小二乘解需要观测数 ≥ 6（超定系统 `Aθ=z`，`A∈R^{n×6}`）。n=18 时自由度冗余 3 倍，奇异值分解中 `A^T A` 条件数受控。

**Step 2 — 采样冗余的平均效果。** 有放回采样 n 次，每个 token 被采样次数 `N_t ~ Binomial(n, 1/8)`，期望 `E[N_t] = n/8`。n=18 时 `E[N_t]=2.25`，保证多样性；n=64 时 `E[N_t]=8`，大量重复点但无额外几何信息 → 边际收益递减。

**Step 3 — 稳定性扫描实测（Qwen2.5-0.5B，B04=8）。**

| SAMPLES_PER_FRAME | DEFF 均值 | DEFF CV | 相对计算时间 |
|:---:|:---:|:---:|:---:|
| 10 | 1.57 | 3.0% | 1.0× |
| 18 | 1.58 | 1.5% | 1.2× |
| 30 | 1.58 | 1.1% | 1.8× |
| 64 | 1.58 | 1.0% | 3.0× |

18 是 B04=8 约束下的经验最优：提供足够的统计稳定性，计算成本可控。

## ⑤ 数值验证

- **实测值**：SAMPLE=18（已用）；DEFF 均值 1.58、CV 1.5%；10→CV 3.0%、30→1.1%、64→1.0%。
- 验证脚本 [verify.py](verify.py)：验证 8-token 池有放回采样 18 次得 (18,d) 矩阵、平均每 token 采样次数≈2.25、经验关系 `B05≈2×B04+2`，并用噪声下的二次曲面拟合演示 18 点比 10 点更稳定。

## ⑥ 与关联参数的关系

| 配合参数 | 关系 |
|---------|------|
| B04 TOK_PER_FRAME | 每帧 token 数决定可采样的不同点数量；B05 在其基础上有放回采样 |
| B07 K_NN_CURV | 近邻数决定曲率估计的局部性，采样点越多近邻图越稳定 |
| 202 DEFF_A | 每个采样点贡献一个主截面特征值对，最终 DEFF 是所有采样点的聚合 |
| B06 N_SAMPLE_PER_FRAME | 数值相同但属版本 A 独立模块，应保持同步 |
