## ① 定义

`D02 fit_range` 定义卡方拟合时使用的角度范围：**0.5° 到 38.5°，共 39 格**（每格 0.5°，与 `D01 bins` 同口径）。在 φ 分布直方图中，两端格点存在统计问题：

- **0° 附近**：管状结构（κ₂≈0）样本稀少，计数统计噪声大；
- **45° 附近**：各向同性鞍面边缘区域，同样样本稀疏；
- **极端角度**可能来自数值伪影（曲率估计误差）。

`fit_range` 剔除尾部极端格点（0° 端前 2 格 + 45° 端后 8 格，文档口径），只保留中心 **39 格**（0.5°-38.5°）用于分布拟合。

**源码实际实现**（`_phi_fit_chi2.py` 行 86-94）：`bins=np.linspace(0,45,46)`（1° 格 45 格），`fit_idx = np.arange(39)` 取前 39 格（中心 0.5°-38.5°），尾部 `obs_full[39:]`（39.5°-45°）单独报告。主文档"0.5° 格 39 格"与源码"1° 格 39 格"口径存在差异（见 ⑤ 审计），但**"剔除尾部只留中心 39 格"的原则一致**。

## ② 公式

拟合域裁剪：

```python
counts_full, edges = np.histogram(phi_deg, bins=np.linspace(0, 45, 46))  # D01
fit_idx = np.arange(39)                       # 源码：前 39 格 = 中心 0.5-38.5°
obs_fit = counts_full[fit_idx]                # 拟合用观测频数
tail    = counts_full[39:].sum()              # 尾部 39.5-45° 单独报告
```

χ² 统计量（只在拟合域上计算）：

$$\chi^2 = \sum_{i \in \text{fit\_range}} \frac{(O_i - E_i)^2}{E_i + \epsilon},\qquad \epsilon=10^{-10}$$

BIC 模型选择：

$$\text{BIC} = \chi^2 + k \ln n,\qquad n = \sum_{i} O_i$$

其中 k 为模型参数个数（M1:0, M2:1, M3:2, M4:3）。

## ③ 物理/几何直觉与用途

**物理直觉**：φ 分布两端是"测量伪影高发区"——管状点（φ→0°）和鞍面边缘点（φ→45°）在真实激活流形上占比低、曲率估计不稳。把它们纳入 χ² 会让 μ、σ 的最优值向尾部偏移，扭曲模型参数估计。

**几何直觉**：鞍面主导流形的 φ 分布主峰在 14°-22°，中心 39 格（0.5°-38.5°）恰好覆盖主峰 + 两翼的主体区域；尾部 6 格（>38.5°）是低统计量噪声区，剔除后拟合更稳、更可重复。

**用途**：`D02` 是 M1-M4 四模型 χ² 拟合的**统一计算域**——所有模型的期望频数都只在中心 39 格上比较。实测证明：全范围拟合 M3 p=0.85，拟合域拟合 M3 **p=0.91**，剔除尾部显著改善拟合优度。

## ④ 推导过程

**第一步（行 2089-2095）：构建全范围直方图（D01）。** 45 格（源码）或 46 格（文档）。

**第二步（行 2097-2108）：截取拟合域。** 剔除尾部约 10-15% 格点，保留中心主峰区。文档示例（0.5° 格口径）：

```python
counts_fit = counts_full[1:78]   # 0.5°格：索引1-77，剔除0°端2格+45°端8格
```

（文档行 2108 自注：0.5°-38.5° 跨度 38°，@0.5° 步长为 77 格而非 39 格——**口径需结合格点定义确认**；源码 1° 格下 `np.arange(39)` 恰好是 39 格。）

**第三步（行 2110-2119）：拟合域上 χ² 拟合。** 对 M1-M4 分别算期望频数、χ²。

**第五步（行 2134-2140）：判决。** 实测 M3 χ²=42.1, BIC=49.9 最优；M4 χ²=39.8 但 Δχ²=2.3<5.99，尖峰不显著。

**⚠️ 审计发现（文档-源码不一致）**：
- 主文档行 2065/2073 声称"0.5°-38.5° **39 格**"、剔除"0°端 2 格 + 45°端 8 格"（2+8=10，46-10=36≠39）；

- **结论**：剔除尾部、保留中心主峰的原则一致；精确格数（39 vs 77）随格宽口径而变，源码口径（1° 格 39 格）为可复现实现。
