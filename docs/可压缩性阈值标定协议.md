# 可压缩性阈值标定协议（v0 草案，待执行）

> 依据：`research-baseline-builder` 方法（先定"输入→输出→样本单位→成功判据"，再定基线层级，不凭空标定）。
> 目标：把 `schema.COMPRESS_HIGH=0.45` / `COMPRESS_MID=0.35` 从 **推测级（heuristic）** 升级为 **实测级（measured）**。本文件是执行前契约，不是结果。

## 1. 科学问题（一句话）
能否用"谱集中度 γ ∈ [0,1]"作为 KV 缓存按层剪枝的**可用前置判据**——即给定精度保留阈值，γ 落在哪个区间时剪枝安全？

## 2. 输入-输出契约
| 角色 | 定义 |
|------|------|
| 输入 | 每层 k_proj / o_proj 激活经 `harness.spl_gamma` 得到的逐层 γ（真实实测，暂含当前 5 档存档） |
| 干预 | KV 剪枝率 `p ∈ {0.25,0.5,0.6}` 的逐层阈值化 low-rank / token 丢弃 |
| 输出 | 剪枝后与全精度对照的任务精度保留率 `AR = acc_pruned / acc_full` |
| 样本单位 | **单个 模型 × 规则 × 剪枝率** 的一次评估（不是单 token） |
| 标签 | 安全/中/危险：`AR` 是否达标的布尔 + 连续 `AR` |
| 成功判据 | 找到与 γ 有稳定单调关系、可跨模型的剪枝安全切点（对应 0.35/0.45 的升级） |

## 3. 数据契约 / 失效风险
- 特征**禁止**用行 ID / 模型名直接当预测特征（会过拟合家族），只允许测量量（γ、DEFF、层深）。
- 精度保留演化随剪枝率单调下降是预期基准；若出现"剪更多反而更准"（蒸馏型正则），判定口径必须显式记录。
- 现 5 档样本量太小，任何结论都需标注"有限样本、待扩"。

## 4. 基线层级（按序跑，先快后强）
1. **sanity**：多数类（"全部安全/全部危险"）—— 给出不可突破的下限。
2. **规则/可解释**：`γ_θ 阈值搜索`（线扫 γ 在 [0.15..0.6] 上找 AR 达标的最优单调切点）→ 直接对标现 0.35/0.45。
3. **强基线**：按**模型级分组**的 per-model 校准 + 留一模型交叉验证（leave-one-model-out），统计切点跨模型稳定性。
4. （可选）神经基线只有当跨模型非线性充足时才上；默认不用，避免过度建模。

## 5. 划分与泄漏
- **严禁随机按行划分**：同一模型的 γ 与 AR 高度相关，必须**按模型分组**（grouped），跨模型泛化。
- 误差带必报：切点给 `中位数 ± 90%CI`，重叠则不得声称"有稳定切点"。

## 6. 主/次指标
- 主：`AR`（任务精度保留率，任务=模型原任务集）。
- 次：KV 内存节省率 `1 - pruned/total`；剪枝后困惑度增量（如可用）。
- 不确定性：跨模型切点区间、留一模型外推误差。

## 7. 输出形态
- 回填 `schema.py` 的 `COMPRESS_HIGH/MID/LOW`，证据级 `heuristic → measured`；
- 更新 `EVIDENCE` 映射与 report 徽标；
- 归档每个 (模型,γ,AR) 原始行，供复现审计。
