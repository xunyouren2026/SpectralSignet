# aiq-geometric-forensics 使用指南

> AI 几何指纹诊断包 —— 输入任意模型，输出几何健康画像 + 家族溯源 + 基准对比。
> 以真实实测为准（Qwen / Llama / BLOOM 三家族共 5 个 0.5–1.5B 模型标定），拒绝合成水分值。

## 1. 它是什么

这是一个**可导入的 Python 包**，把 59 参数验证体系的真实测量引擎封装为三大函数式能力：

| 能力 | 函数 | 回答的问题 |
|------|------|-----------|
| 几何健康度诊断 | `diagnose()` | 模型健不健康？AIQ 几何智能商多少？可压缩吗？ |
| 家族溯源判定 | `trace()` | 模型是不是某家族成员？微调后还在不在？ |
| 与基准对比 | `compare()` | 与基准模型差多少？能归到已知家族吗？ |
| 真实模型测量 | `measure()` | 对本地模型实测真实指标（需 torch/transformers） |

## 2. 快速上手（零安装，直接导入）

```python
# 在本包根目录下运行（modules 为包内模块）
from modules import diagnose, format_health, trace, format_trace, compare, format_compare

# ① 健康画像 —— 默认用 Qwen2.5-0.5B-Instruct 真实实测存档
print(format_health(diagnose("Qwen2.5-0.5B-Instruct")))

# ② 家族溯源 —— base（预训练）vs Instruct（SFT）
print(format_trace(trace("Qwen2.5-0.5B", "Qwen2.5-0.5B-Instruct")))

# ③ 基准对比
print(format_compare(compare("Qwen2.5-0.5B", "Qwen2.5-0.5B-Instruct")))
```

直接跑完整 4 大用例：

```bash
python aiq_forensics_demo.py
```

## 3. 对任意模型做体检

### 方式 A：已有真实测量 dict（推荐，最快）
把 `measure()` 或 `aiq_forensics_demo.py` 产出的标准 measurement dict 直接传入：

```python
from modules import diagnose, format_health
measurement = {...}                      # 与 baselines/<模型名>.json 同构的标准 dict
print(format_health(diagnose("my-model", measurement=measurement)))
```

### 方式 B：直接测量本地模型（需 torch + transformers）
```python
from modules import measure, diagnose, format_health
m = measure("path/to/local-model")       # 真实前向测量
print(format_health(diagnose("my-model", measurement=m)))
```
就是用一个新的 Qwen2.5-0.5B base 或任意本地 HF 模型做家族溯源、健康度、压缩比诊断。命令行等价：

```bash
python -m modules.harness --model-dir "Qwen2.5-0.5B" --out my_metrics.json
```

### 方式 C：把新模型加入基准库（扩展指纹库）
```python
from modules import measure
import json
m = measure("path/to/new-family-model")
with open("baselines/NewFamily.json", "w", encoding="utf-8") as f:
    json.dump(m, f, ensure_ascii=False, indent=2)
```
之后 `diagnose("NewFamily")` / `trace("NewFamily", "Qwen2.5-0.5B-Instruct")` 即可识别新家族。

## 4. 输出解读

### 健康画像
- `AIQ 几何智能商`：0-100 综合分，由五因子加权（f1 芯坍缩 / f2 DEFF 稳定 / f3 H 收敛 / f4 SPL 集中 / f5 低模纯度）。
- **f2 判别力提示**：因 DEFF_cv 在各模型均 ≈0.19，f2 在基准库近乎恒定，属"基线项"，对模型排序无贡献（跨家族报告"因子判别度诊断"表会显式呈现各因子判别力分级）。
- `健康判定` 三判据：`K%槽内[20,57]`（鞍形主导正常）、`DEFF平台`（本包按区间+误差带口径：均高于 π/2 约 +0.7%~+2.3%、观测支撑集 `[1.5825,1.6072]`，判定说明会标注"家族标定带内/出带"）、`H收敛`（链长足够）。
- `可压缩性`：按 Gamma 分级——高可压(o/k)激进剪枝，中可压(q/gate/down)温和压缩，难压缩(up/v)保持全精度。**分级的 0.35/0.45 阈值目前为推测级，非实测**（升级协议见 `docs/可压缩性阈值标定协议.md`）。

### 溯源报告
- `|Δμ| 指纹均值差`：base/Instruct 实测差 0.0016 → 指纹是身份度量，非智能度量。
- `MAD 最近邻`：离哪个家族指纹最近（当前单参照，多家庭可扩展基准库）。

### 数据来源标注
每个报告都打印 `数据源:`，标明用的是**真实测量（inline）/ 基准存档（baseline）/ 审计兜底（fallback）**——绝不把兜底伪装成实测。

## 5. 设计原则（为什么这是"专业版"而非普通脚本）

1. **统一架构**：一个可导入包 `modules/`，功能按模块管理，公开入口收敛在 `modules/__init__.py`。
2. **标准接口**：`diagnose() / trace() / compare() / measure()` 一行调用，返回结构化 dict 可序列化。
3. **集中数据层**：`data.Metrics` 统一解析"真实测量 > 基准存档 > 审计兜底"，杜绝散落硬编码。
4. **实时获取 + 真实标定**：DEFF_cv / 层数 / 曲率对 / 架构字段全部从真实测量与各家族 config 实时解析；基准值来自 Qwen/Llama/BLOOM 三家族 5 个模型的真实实测（非文档水分值）。
5. **零硬编码路径**：全包路径基于 `__file__` 相对推导；`sanitize_path()` 还会剔除测量 dict 里的用户绝对路径，不打探隐私。
6. **工程规范**：类型注解、边界防御（空输入/NaN/除零；无实测投影跳过不崩）、`main() -> int` 退出码、统一断言带消息。
7. **报告导出**：`python -m modules.cli ... --html out.html` 导出含证据分级徽标的自包含 HTML；`--json` 导出结构化 JSON；`--log/--json-log/--verbose` 提供可观测结构化日志。
8. **可观测层**：`modules/observation.py` 提供时间戳+级别+模块的日志，支持 JSONL 落盘（CI 可解析）；数据回退/测量副作用均入日志。
9. **可验证**：`tests/run_all_tests.py`(33) + `tests/verify_derivations.py`(56) + `tests/test_robustness.py`(14) + `tests/test_selfcheck.py`(73) 一键回归全绿；`ruff`/`mypy` 静态检查全绿；CI 与 pre-commit 门禁就绪。
10. **发布门禁**：`python -m modules.cli selfcheck` 做生产完整性自检（版本三源一致 / 基准库完整 / 无 NaN / AIQ 无存档漂移 / 证据纪律 / 报告冒烟 / 隐私脱敏），任一失败退出码 2。

│   ├── run_all_tests.py       零依赖回归（33 项断言）

## 7. 与老版 spectral-cognition 的关系

| 维度 | 老版（增强器） | 本包（诊断器） |
|------|--------------|----------------|
| 本质 | 让模型变聪明 | 测模型是谁/健康不健康 |
| 数据 | 合成（有水分） | 真实模型标定 |
| 关系 | 理论同源 | 互补（增强 vs 检测） |
